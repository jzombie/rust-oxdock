# Architecture Plan: Static Enum Dispatch via Macro (v6)

## Problem

Command metadata is scattered across four disconnected sources. Adding or modifying a command requires touching 6 files. The test harness spawns ~50 separate `cargo run` processes per test run, making the feedback loop painfully slow. The goal is **compile-time extensibility** + **in-process execution**.

---

## Critical Flaws Addressed

| # | Flaw | Fix |
|---|------|-----|
| 1 | Closed-world TOML codegen | `CommandSpec` trait + `define_pipeline!` macro |
| 2 | Positional args rejected on flag-enabled commands | Unrecognized `--` args treated as positional |
| 3 | Attached flag values destroy expressions | Keep full `Arg` node; resolve at runtime |
| 4 | `resolve_arg_pure` ignores absent args | `resolve_opt_arg_pure` accepts `Option<&Arg>` |
| 5 | Lowering vs dispatch contradiction | Macro generates both from single declaration |
| 6 | Unhygienic macro paths | `::indoc::indoc!` fully qualified |
| 7 | Source-tree pollution | No `build.rs` — pure macro expansion |
| 8 | Test harness orphanage | `generate_doc_tests!` from trait metadata |
| 9 | `dyn` dispatch overhead | Static enum dispatch — zero heap, zero vtable |

---

## Architecture Overview

```
oxdock-parser                      oxdock-core
┌──────────────────────┐           ┌──────────────────────────────┐
│ CommandSpec trait     │           │ define_pipeline! {           │
│   const NAME         │           │   Write(WriteCmd),           │
│   type Args          │           │   Read(ReadCmd),             │
│   fn metadata()      │           │   ...                        │
│   fn lower()         │           │   MyExt(my_ext::CustomCmd),  │
│   fn execute()       │           │ }                            │
│                      │           │                              │
│ StepKind (generated) │◄──────────│ Generates:                   │
│   Write(WriteArgs)   │           │   - StepKind enum            │
│   Read(ReadArgs)     │           │   - lower_command() match    │
│   MyExt(CustomArgs)  │           │   - execute_command() match  │
│                      │           │                              │
│ parse_script(registry)│          │ parse_script(&lower_command) │
└──────────────────────┘           └──────────────────────────────┘
```

**Key insight:** The `define_pipeline!` macro in `oxdock-core` generates everything — `StepKind` enum, lowering dispatch, execution dispatch — from a single declaration. `oxdock-parser` provides the trait and generic parser; `oxdock-core` wires it all together.

## Solution: 7 Components

### 1. `CommandSpec` Trait (`oxdock-parser/src/command.rs`)

```rust
use crate::ast::{Arg, IoBinding};
use anyhow::Result;

pub struct ArgSpec {
    pub name: &'static str,
    pub arg_type: &'static str,
    pub io: IoDirection,
    pub index: usize,
    pub required: bool,
    pub fallback_stream: Option<Stream>,
}

pub struct FlagSpec {
    pub name: &'static str,
    pub long: &'static str,
    pub value_type: FlagValueType,
    pub required: bool,
    pub description: &'static str,
}

pub struct CommandMeta {
    pub name: &'static str,
    pub syntax: &'static str,
    pub summary: &'static str,
    pub description: &'static str,
    pub args: &'static [ArgSpec],
    pub flags: &'static [FlagSpec],
    pub default_output: Option<Stream>,
    pub examples: &'static [Example],
}

pub struct Example {
    pub name: &'static str,
    pub code: &'static str,
}

/// Every command implements this trait. Fully static — no dyn.
pub trait CommandSpec {
    const NAME: &'static str;
    type Args: Send + Sync;

    fn metadata() -> CommandMeta;
    fn lower(args: Vec<Arg>) -> Result<Self::Args>;
    fn execute<P: ProcessManager>(args: &Self::Args, cx: &mut StepCtx<'_, P>) -> Result<()>;
}
```

### 2. `define_pipeline!` Macro (`oxdock-core/src/pipeline.rs`)

Single macro invocation generates the enum + both dispatch functions:

```rust
#[macro_export]
macro_rules! define_pipeline {
    (
        $( $variant:ident($cmd_type:ty) ),* $(,)?
    ) => {
        // ── Generated StepKind enum ──
        pub enum StepKind {
            $( $variant(<$cmd_type as $crate::CommandSpec>::Args), )*
            // Structural variants (always present)
            WithIo { bindings: Vec<IoBinding>, cmd: Box<StepKind> },
            WithIoBlock { bindings: Vec<IoBinding> },
            For { key_var: Option<String>, var: String, in_expr: Expr, body: Vec<Step> },
            If { cond: Box<Expr>, then_body: Vec<Step>, else_ifs: Vec<(Box<Expr>, Vec<Step>)>, else_body: Option<Vec<Step>> },
            Assign { var: String, expr: Expr },
        }

        // ── Generated lowering dispatch (used by parser) ──
        pub fn lower_command(name: &str, args: Vec<Arg>) -> Result<StepKind> {
            match name {
                $( <$cmd_type as $crate::CommandSpec>::NAME => {
                    Ok(StepKind::$variant(<$cmd_type as $crate::CommandSpec>::lower(args)?))
                } )*
                _ => anyhow::bail!("unknown command: {name}"),
            }
        }

        // ── Generated execution dispatch ──
        pub fn execute_command<P: ProcessManager>(
            step: &StepKind,
            cx: &mut StepCtx<'_, P>,
        ) -> Result<()> {
            match step {
                $( StepKind::$variant(args) => {
                    <$cmd_type as $crate::CommandSpec>::execute(args, cx)
                } )*
                // Structural variants dispatched separately
                StepKind::WithIo { bindings, cmd } => $crate::handlers::with_io(cx, bindings, cmd),
                StepKind::For { .. } => $crate::handlers::for_loop(cx, step),
                StepKind::If { .. } => $crate::handlers::if_then(cx, step),
                StepKind::Assign { .. } => $crate::handlers::assign(cx, step),
                _ => anyhow::bail!("structural variant in execute_command"),
            }
        }

        // ── Generated metadata registry (for docs-gen) ──
        pub fn all_metadata() -> Vec<$crate::CommandMeta> {
            vec![
                $( <$cmd_type as $crate::CommandSpec>::metadata(), )*
            ]
        }
    };
}
```

### 3. Command Implementation Example

Each command is a unit struct with `CommandSpec`:

```rust
pub struct WriteCmd;

impl CommandSpec for WriteCmd {
    const NAME: &'static str = "WRITE";
    type Args = WriteArgs;

    fn metadata() -> CommandMeta {
        CommandMeta {
            name: "WRITE",
            syntax: "WRITE <path> [<contents>]",
            summary: "Writes data to a file from string content or stdin.",
            description: "Writes contents to a file, replacing any existing \
                           contents. Creates parent directories on demand. \
                           Without a contents argument it consumes stdin.",
            args: &[
                ArgSpec { name: "path", arg_type: "Path", io: IoDirection::Write, index: 0, required: true, fallback_stream: None },
                ArgSpec { name: "contents", arg_type: "String", io: IoDirection::Read, index: 1, required: false, fallback_stream: Some(Stream::Stdin) },
            ],
            flags: &[],
            default_output: None,
            examples: &[
                Example { name: "Direct write", code: "WRITE dist/hello.txt \"Built with OxDock\"\nASSERT_FILE dist/hello.txt \"Built with OxDock\"" },
            ],
        }
    }

    fn lower(args: Vec<Arg>) -> Result<WriteArgs> {
        let mut positional = args;
        let path = positional.remove(0).ok_or("WRITE requires path")?;
        let contents = positional.into_iter().next();
        Ok(WriteArgs { path, contents })
    }

    fn execute<P: ProcessManager>(args: &WriteArgs, cx: &mut StepCtx<'_, P>) -> Result<()> {
        handlers::write(cx, /* idx */ 0, &args.path, args.contents.as_ref())
    }
}

pub struct WriteArgs {
    path: Arg,
    contents: Option<Arg>,
}
```

### 4. Flag Handling + Lowering Flow

**`strip_flags` with POSIX `--` + unrecognized arg tolerance:**

```rust
pub fn strip_flags<'a>(
    args: &'a [Arg],
    meta: &CommandMeta,
) -> Result<(Vec<(String, Arg)>, Vec<&'a Arg>)> {
    if meta.flags.is_empty() {
        return Ok((Vec::new(), args.iter().collect()));
    }

    let mut flags = Vec::new();
    let mut positional = Vec::new();
    let mut i = 0;
    while i < args.len() {
        match &args[i] {
            Arg::String(s) if s == "--" => {
                positional.extend(args[i + 1..].iter());
                break;
            }
            Arg::String(s) if s.starts_with("--") => {
                let (flag_name, eq_pos) = if let Some(eq) = s.find('=') {
                    (&s[2..eq], Some(eq))
                } else {
                    (&s[2..], None)
                };
                match meta.flags.iter().find(|f| f.long == format!("--{flag_name}")) {
                    Some(flag_meta) => {
                        let value = match flag_meta.value_type {
                            FlagValueType::Flag => Arg::String("true".into()),
                            _ => {
                                if let Some(eq) = eq_pos {
                                    Arg::String(s[eq + 1..].to_string())
                                } else {
                                    i += 1;
                                    args.get(i).cloned()
                                        .ok_or_else(|| anyhow!("--{flag_name} requires a value"))?
                                }
                            }
                        };
                        flags.push((flag_meta.name.to_string(), value));
                    }
                    None => positional.push(&args[i]),
                }
            }
            other => positional.push(other),
        }
        i += 1;
    }
    Ok((flags, positional))
}
```

**Lowering flow in `parse_script()`:**

```
1. PEG parse → StepKind::Generic { name, args }  (parser-internal)
2. lookup metadata from all_metadata()
3. strip_flags(args, meta) → (flags, positional_args)
4. lower_command(name, positional_args) → StepKind::Write(WriteArgs { .. })
   (for commands with flags, lower receives flags separately)
5. Return Vec<Step> with typed StepKind variants
```

For commands with flags (like ASSERT_FILE), the lowering path is:

```
strip_flags → flags = [("hash", "abc123")], positional = ["path"]
lower_with_flags(name, flags, positional) → StepKind::AssertFile(AssertFileArgs { hash: Some("abc123"), path: "path" })
```

`lower_with_flags` is a second generated function:

```rust
pub fn lower_with_flags(
    name: &str,
    flags: Vec<(String, Arg)>,
    args: Vec<Arg>,
) -> Result<StepKind> {
    match name {
        "ASSERT_FILE" => {
            let hash = flags.into_iter().find(|(k,_)| k == "hash").map(|(_,v)| v);
            let path = args.into_iter().next().ok_or("ASSERT_FILE requires path")?;
            let contents = args.into_iter().next();
            Ok(StepKind::AssertFile(AssertFileArgs { hash, path, contents }))
        }
        // For commands without flags, delegate to lower_command
        _ => lower_command(name, args),
    }
}
```

### 5. Pure Argument Resolution

```rust
pub(crate) enum ArgValue {
    Resolved(String),
    StdinFallback,
    None,
}

pub(crate) fn resolve_opt_arg_pure(
    arg: Option<&Arg>,
    fallback: Option<Stream>,
    cx: &ExecState,
) -> Result<ArgValue> {
    match (arg, fallback) {
        (Some(a), _) => match a {
            Arg::String(s) => Ok(ArgValue::Resolved(expand_string(s, cx)?)),
            Arg::Expr(e) => Ok(ArgValue::Resolved(format_value(evaluate_expr(e, cx)?))),
        },
        (None, Some(Stream::Stdin)) => Ok(ArgValue::StdinFallback),
        (None, _) => Ok(ArgValue::None),
    }
}
```

```rust
            use super::*;

            // Each becomes a standard #[test] function
```

**c) `CaseRoot` + `verify_result` helpers (reuse existing assertion logic):**

```rust
/// In-process test root — creates temp dirs, runs setup, provides verification.
pub struct CaseRoot {
    snapshot: GuardedTempDir,
    local: GuardedTempDir,
}

impl CaseRoot {
    pub fn new(case: &CaseSpec) -> Self {
        let snapshot = GuardedTempDir::new().unwrap();
        let local = GuardedTempDir::new().unwrap();
        // Run setup function if specified (e.g., create git repo)
        if let Some(setup) = &case.setup {
            run_setup(setup, &snapshot, &local, case.build_context.as_deref());
        }
        Self { snapshot, local }
    }
    pub fn snapshot(&self) -> &GuardedPath { self.snapshot.as_guarded_path() }
    pub fn local(&self) -> &GuardedPath { self.local.as_guarded_path() }
}

/// Verify expectations — same logic as current ast_commands/main.rs but in-process.
pub fn verify_result(
    result: &Result<Vec<Step>, anyhow::Error>,
    case: &CaseSpec,
    root: &CaseRoot,
) {
    if let Some(expected_error) = &case.expect_error_contains {
        match result {
            Err(e) => assert!(e.to_string().contains(expected_error), ...),
            Ok(_) => panic!("expected error containing '{expected_error}', got success"),
        }
        return;
    }
    result.as_ref().unwrap(); // propagate unexpected errors
    // Verify files, missing files, dirs, stdout, platform-specific, etc.
    // Reuse the existing verify_expectations() logic from ast_commands/main.rs
    verify_expectations(&case.expect, root);
}
```

## Implementation Phases

### Phase 1: Trait + Macro Foundation
- Define `CommandSpec`, `CommandMeta`, `ArgSpec`, `FlagSpec` in `command.rs`
- Implement `define_pipeline!` macro in `pipeline.rs`
- Add `strip_flags` with POSIX `--` support
- Verify: `cargo build -p oxdock-parser -p oxdock-core`

### Phase 2: Generic PEG + Lowering Integration
- Remove command-specific PEG rules from `dsl.pest`
- `parse_script()` accepts lowering fn parameter
- Generic `instruction` rule extracts command name + raw args
- Wire `lower_command` from `define_pipeline!` into parser
- Verify: `cargo test -p oxdock-parser` — parse-time errors for invalid scripts

### Phase 3: Migrate Built-In Commands
- Implement `CommandSpec` for all 24 built-in commands (one struct each)
- `define_pipeline!` invocation lists all commands
- Wire `execute_command` into `steps.rs` dispatch
- Verify: `cargo test --workspace --tests`

### Phase 4: Pure Arg Resolution
- Add `ArgValue` + `resolve_opt_arg_pure`
- Update handler signatures for typed args
- Verify: `cargo test -p oxdock-core`

### Phase 5: Docs + Test Harness (Metadata)
- Generate `07-command-body.md` from `all_metadata()`
- Generate `generate_doc_tests!` from examples
- Verify: `cargo run -p docs-gen` + `cargo test -p oxdock-logic-tests`

### Phase 6: In-Process Execution Harness (Speed)
- Implement `CaseRoot`, `verify_result`, `load_case` in `oxdock-logic-tests/src/lib.rs`
- Implement `generate_case_tests!` macro (reads case dirs, emits #[test] fns)
- Migrate all 49 cases from `ast_commands/cases/` to in-process tests
- Delete `ast_commands/` fixture project + `commands_harness.rs`
- Delete `coverage.toml` + `assert_coverage()` + text-scanning
- Verify: `cargo test -p oxdock-logic-tests` — all cases pass, ~10x faster
