# README Template System for oxdock-rs

## Goal

Create a composable documentation system where:
1. The main `README.md` is assembled from template sections via an OxDock script
2. The command reference is auto-generated from the PEG grammar / `Command` enum
3. **Every sub-crate README** is generated dynamically from a shared template + source content files
4. The system dogfoods the OxDock DSL

## Core Principle: Source files are the single source of truth

The generator is a **pure renderer** — it reads source content files and template definitions, expands placeholders, and writes output. It does **not** extract content from existing READMEs or README-DRAFTs at runtime. All prose is migrated into the template system's source files during setup, and the original README-DRAFT.md files are deleted.

```
Source of truth:                    Renderer:              Output:
docs/sections/*.md          ──┐
docs/crates/<name>/*.md     ──┼──→ docs-gen binary ──→ README.md
                                │                     <crate>/README.md
docs/templates/crate-readme.md ─┘
```

---

## Architecture

### Design Decision: Composition via Rust binary, orchestrated by OxDock

OxDock's `EXPAND` outputs to stdout with no capture mechanism. The architecture splits responsibilities:

- **`docs-gen` binary** — reads source content files, expands `{{ env:KEY }}` placeholders, concatenates into final output, generates command reference from grammar
- **`assemble-readme.oxdock`** — the documented entry point that calls `docs-gen` and verifies output

## Template System

### Main README template

The main README is assembled by concatenating `docs/sections/*.md` in order. Section `06-command-reference.md` is auto-generated by the binary from the PEG grammar.

### Crate README template: `docs/templates/crate-readme.md`

```markdown
# {{ env:CRATE_NAME }}

{{ env:CRATE_DESCRIPTION }}

> Part of the [OxDock](https://github.com/jzombie/rust-oxdock) workspace.

## Overview

{{ env:CRATE_OVERVIEW }}

## Quick Start

{{ env:CRATE_QUICK_START }}

## API

{{ env:CRATE_API }}

## License

`{{ env:CRATE_NAME }}` is distributed under the terms of the Apache License (Version 2.0).
```

### How `crate_readme.rs` resolves each placeholder

The generator reads `docs/crates/<name>/` directory and maps files to template variables:

| Placeholder | Source file | Fallback |
|-------------|-----------|----------|
| `CRATE_NAME` | `Cargo.toml` `[package].name` | — |
| `CRATE_DESCRIPTION` | `Cargo.toml` `[package].description` | "No description" |
| `CRATE_OVERVIEW` | `docs/crates/<name>/overview.md` | "Part of the OxDock workspace." |
| `CRATE_QUICK_START` | `docs/crates/<name>/quick-start.md` | "See the [API documentation](https://docs.rs/{name})." |
| `CRATE_API` | `docs/crates/<name>/api.md` | "See the [API documentation](https://docs.rs/{name})." |

Each source `.md` file is read as-is and inserted into the template. No parsing, no extraction — just file → placeholder mapping.

## Implementation Steps

### Step 1: Create `crates/docs-gen` binary crate

**`Cargo.toml`** — depends on `oxdock-parser` (for `Command`, `COMMANDS`, `LANGUAGE_SPEC`), `anyhow`.

**`src/main.rs`** — CLI with three subcommands:
- `assemble-readme` — read section files, concatenate → README.md
- `generate-command-ref` — parse grammar, write command reference table to `docs/sections/06-command-reference.md`
- `generate-crate-readmes` — for each crate dir in `docs/crates/`, expand template and write to `<crate>/README.md`

### Step 2: Implement `command_ref.rs`

Reads `dsl.pest` and extracts command metadata:

1. Parse each `*_command` rule line to get the keyword (from the quoted string)
2. Map the argument pattern to a human-readable syntax string
3. Use `Command::COMMANDS` for the canonical ordering
4. Generate the summary table and anchor links

The per-command prose stays in `docs/sections/07-command-body.md` — only the table is auto-generated.

Grammar parsing strategy for each rule line like:
```
workdir_command = ${ "WORKSPACE" ~ sep ~ workspace_target }
```
Extract: keyword = `WORKSPACE`, arguments = `SNAPSHOT|LOCAL` → syntax = `WORKSPACE SNAPSHOT|LOCAL`

### Step 3: Implement `sections.rs`

1. Read all `docs/sections/*.md` files in sorted order
2. Concatenate their contents
3. Write to stdout (or file if `--output` specified)

No template expansion needed for the main README sections — they are static markdown. Template variables are only used in crate READMEs.

### Step 4: Implement `crate_readme.rs`

1. Read `docs/templates/crate-readme.md`
2. Discover all directories under `docs/crates/`
3. For each crate directory:
   - Read `Cargo.toml` for name + description
   - Read each `.md` file in the crate dir
   - Map filenames to template placeholders (overview.md → `{{ env:CRATE_OVERVIEW }}`)
   - Expand template
   - Write to `<crate>/README.md`

### Step 5: Migrate existing content into source files

For crates with existing README-DRAFT.md or substantive README.md:
1. Parse the markdown into sections by `##` headers
2. Write each section to the appropriate `docs/crates/<name>/<section>.md` file
3. Delete the README-DRAFT.md files

For crates with no existing content:
1. Read `src/lib.rs` doc comments
2. Write overview and API content to `docs/crates/<name>/` files

### Step 6: Split current README into section files

Extract lines from current `README.md` into the numbered section files. No content changes — just splitting at section boundaries.

### Step 7: Create `docs/templates/assemble-readme.oxdock`

```oxdock
// README Assembly Script
// Run: oxdock --script docs/templates/assemble-readme.oxdock
// Or:  cargo run -p docs-gen -- assemble-readme

ENV REPO_ROOT=.

// Phase 1: Generate the command reference table from the grammar
[unix] RUN cargo run --manifest-path crates/docs-gen/Cargo.toml -- generate-command-ref
[windows] RUN cargo run --manifest-path crates/docs-gen/Cargo.toml -- generate-command-ref

// Phase 2: Assemble final README from all sections
[unix] RUN cargo run --manifest-path crates/docs-gen/Cargo.toml -- assemble-readme --output README.md
[windows] RUN cargo run --manifest-path crates/docs-gen/Cargo.toml -- assemble-readme --output README.md

// Phase 3: Generate all sub-crate READMEs
[unix] RUN cargo run --manifest-path crates/docs-gen/Cargo.toml -- generate-crate-readmes
[windows] RUN cargo run --manifest-path crates/docs-gen/Cargo.toml -- generate-crate-readmes
```

### Step 8: Wire into workspace and tests

- Add `crates/docs-gen` to workspace `Cargo.toml` members
- Add a test that runs `docs-gen assemble-readme` and diffs against checked-in README
- Existing `readme_snippets_*` tests continue to validate the final output
