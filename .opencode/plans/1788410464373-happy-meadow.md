# Plan: Migrate Slow DSL Tests to In-Process

## Problem

The `commands_harness` compiles a Rust sub-crate (`ast_commands`) **~48 times** via `cargo run --quiet`. Even with shared `CARGO_TARGET_DIR`, each `cargo run` pays cargo startup overhead (manifest parsing, timestamp checking, dependency resolution). The in-process tests in `oxdock-core/tests/commands.rs` run in 0.52s.

## Implementation Steps (Status)

### Step 1: In-process tests — DONE
16 new tests + exhaustiveness check in `oxdock-core/tests/commands.rs`. 52 tests, 0.52s parallel.

### Step 2: Smoke filter in harness — DONE
`commands_harness.rs` runs 2 cases (`write`, `with_io`) by default. `--features slow-integration` runs all 48 + coverage.

### Step 3: Compile-once for full suite (DIRECTIVE FROM CODE REVIEW)

The remaining performance issue: even with the smoke filter, the full 48-case suite (`--features slow-integration`) still compiles the binary 48 times.

**Approach**: Pre-compile `ast_commands` once via `cargo build --message-format=json`, extract the exact binary path from Cargo's JSON IPC, then run the pre-built binary directly for each test case — no per-case `cargo run` overhead.

#### 3a. Add `precompiled_binary: Option<PathBuf>` to `HarnessConfig`

```rust

```

Initialize to `None` in `HarnessConfig::new`.

#### 3b. Pre-compile in `commands_harness.rs` main (full-suite mode only)

Use `cargo build --message-format=json-render-diagnostics` to get the exact binary path from Cargo's compiler-artifact JSON messages:

```rust
#[cfg(not(miri))]
fn main() {
    // ... existing arg parsing, resolver, fixtures_root setup ...

    let precompiled = if cfg!(feature = "slow-integration") {
        let workspace_root = oxdock_fs::discover_workspace_root()
            .expect("locate workspace root");
        let template = fixtures_root.join("ast_commands")
            .expect("resolve ast_commands template");

        let mut build_cmd = oxdock_process::CommandBuilder::new("cargo");
        build_cmd.arg("build");
        build_cmd.arg("--message-format=json-render-diagnostics");
        build_cmd.current_dir(template.as_path());
        if let Some(target) = &shared_target {
            build_cmd.env("CARGO_TARGET_DIR", oxdock_fs::command_path(target));
        }

        let output = build_cmd.output().expect("pre-compile ast_commands");
        if !output.status.success() {
            let stderr = String::from_utf8_lossy(&output.stderr);
            panic!("pre-compilation of ast_commands failed:\n{stderr}");
        }
        let stdout = String::from_utf8_lossy(&output.stdout);

        // Parse Cargo JSON stream — use artifact.executable (not filename suffix matching)
        let binary = stdout.lines()
            .filter_map(|line| serde_json::from_str::<cargo_metadata::Message>(line).ok())
            .filter_map(|msg| match msg {
                cargo_metadata::Message::CompilerArtifact(artifact)
                    if artifact.target.name == "ast_commands" => artifact.executable,
                _ => None,
            })
            .next()
            .map(|p| p.into_std_path_buf().canonicalize().expect("canonicalize binary path"))
            .expect("ast_commands executable not found in cargo build JSON output");

        Some(binary)
    } else {
        None
    };

    let mut config = HarnessConfig::new("commands", fixtures_root);
    // ... existing config fields ...
    config.precompiled_binary = precompiled;

    // ... rest of main ...
}
```

Add `cargo-metadata` to `[dev-dependencies]` in `Cargo.toml`:
```toml
cargo-metadata = "0.19"
```

#### 3c. Modify `run_fixture_inner` in `src/lib.rs` to use pre-built binary

When `config.precompiled_binary` is `Some` and the fixture matches `case_config.fixture_name`:

1. Skip `FixtureBuilder` / `instantiate()` (no temp copy needed)
2. Run the pre-built binary directly with env vars:
   - `CARGO_MANIFEST_DIR` → original template path (so binary finds `cases/` and `coverage.toml`)
   - `OXDOCK_AST_CASE` → case name
   - `CARGO_TARGET_DIR` → shared target dir (if configured)
3. **Spawn stdin writer on a separate thread** to avoid pipe deadlock
4. Assert exit status, stdout, stderr as before

```rust
fn run_fixture_inner(config, spec, case) -> Result<()> {
    // Pre-compiled fast path: skip fixture copy, run binary directly
    if let (Some(binary), Some(case_config)) = (&config.precompiled_binary, &config.case_config) {
        if spec.name == case_config.fixture_name {
            return run_precompiled_case(config, spec, case, case_config, binary);
        }
    }
    // ... existing FixtureBuilder path for integration fixtures ...
}
```

The `run_precompiled_case` function (with deadlock-safe stdin handling):

```rust
fn run_precompiled_case(
    config: &HarnessConfig,
    spec: &FixtureSpec,
    case: &FixtureCase,
    case_config: &CaseConfig,
    binary: &Path,
) -> Result<()> {
    #[allow(clippy::disallowed_types, clippy::disallowed_methods, clippy::disallowed_macros)]
    {
        use std::io::Write;
        use std::process::{Command, Stdio};
        use std::thread;

        let template_path = Path::new(&spec.template);
        let mut cmd = Command::new(binary);
        cmd.env("CARGO_MANIFEST_DIR", template_path);
        for (key, value) in &case.env {
            cmd.env(key, value);
        }
        for key in &case.env_remove {
            cmd.env_remove(key);
        }
        if let Some(target) = &config.shared_target_dir {
            cmd.env("CARGO_TARGET_DIR", oxdock_fs::command_path(target));
        }

        // Symlink capability check — independent of shared_target_dir
        let needs_symlink = case.name.contains("symlink")
            || case.name == "copy_broken_symlink"
            || case.name == "copy_complex";
        if needs_symlink && !oxdock_sys_test_utils::can_create_symlinks(template_path) {
            eprintln!("skipping {}::{}: symlink unsupported", spec.name, case.name);
            return Ok(());
        }

        // Only pipe stdin when the case provides input; otherwise null it
        if case.stdin.is_some() {
            cmd.stdin(Stdio::piped());
        } else {
            cmd.stdin(Stdio::null());
        }
        cmd.stdout(Stdio::piped()).stderr(Stdio::piped());
        let mut child = cmd.spawn().context("spawn pre-compiled binary")?;

        // Write stdin on a dedicated thread to avoid pipe deadlock:
        // child may emit stdout/stderr before reading all of stdin.
        let stdin_handle = if let Some(stdin_content) = &case.stdin {
            let mut stdin = child.stdin.take().expect("stdin was piped");
            let content = stdin_content.clone();
            Some(thread::spawn(move || {
                let _ = stdin.write_all(content.as_bytes());
                // stdin dropped here — EOF delivered to child
            }))
        } else {
            None
        };

        let result = child.wait_with_output().context("wait for pre-compiled binary")?;
        if let Some(handle) = stdin_handle {
            let _ = handle.join();
        }

        let (status, stdout_bytes, stderr_bytes) = (result.status, result.stdout, result.stderr);
        let stdout = String::from_utf8_lossy(&stdout_bytes);
        let stderr = String::from_utf8_lossy(&stderr_bytes);

        // Assert status, stdout_contains, stderr_contains (same as existing)
        if case.expect_success && !status.success() {
            anyhow::bail!("{}::{} failed. stdout:\n{}\nstderr:\n{}",
                spec.name, case.name, stdout, stderr);
        }
        if !case.expect_success && status.success() {
            anyhow::bail!("{}::{} unexpectedly succeeded. stdout:\n{}\nstderr:\n{}",
                spec.name, case.name, stdout, stderr);
        }
        if let Some(expectation) = &case.error_expectation {
            if status.success() {
                anyhow::bail!("{}::{} expected error, got success", spec.name, case.name);
            }
            super::expectations::assert_text_matches(
                expectation, &stderr,
                &format!("{}::{} error output", spec.name, case.name),
            )?;
        }
        assert_contains(&stdout, &case.stdout_contains, "stdout", spec)?;
        assert_not_contains(&stdout, &case.stdout_not_contains, "stdout", spec)?;
        assert_contains(&stderr, &case.stderr_contains, "stderr", spec)?;
        assert_not_contains(&stderr, &case.stderr_not_contains, "stderr", spec)?;
        Ok(())
    }
}
```

#### Result

- Default `cargo test --test commands_harness` → 2 smoke tests (no pre-compilation)
- `cargo test --test commands_harness --features slow-integration` → 1 `cargo build` via JSON IPC + 48 direct binary invocations (no per-case cargo overhead, no pipe deadlocks, platform-correct binary paths)
