# Plan: Clap Migration + OxDock REPL

## Goal

1. Migrate CLI argument parsing from hand-rolled to clap
2. Default to an interactive OxDock REPL when no script is provided and stdin is a terminal
3. Keep backward compatibility: `--script <file>`, `--script -`, piped stdin

## New Default Behavior

| Invocation | Behavior |
|---|---|
| `oxdock` (terminal, no args) | Enter OxDock REPL |
| `oxdock` (piped stdin) | Execute stdin (existing) |
| `oxdock script.oxdock` | Execute file (new positional arg) |
| `oxdock --script file.oxdock` | Execute file (backward compat) |
| `oxdock --script -` | Execute stdin explicitly |
| `oxdock --shell` | Execute initial script, then host shell (existing) |
| `oxdock --repl` | Force REPL even with piped stdin |

### 2. Clap struct (`oxdock-cli/src/lib.rs`)

Replace `Options` and `ScriptSource` with:

```rust
use clap::{Parser, ValueEnum};

#[derive(Parser)]
#[command(name = "oxdock", about = "Execute OxDock scripts")]
struct Cli {
    /// Script file to execute (use - for stdin)
    #[arg(short, long)]
    script: Option<String>,

    /// Drop into host shell after execution
    #[arg(long)]
    shell: bool,

    /// Force REPL mode
    #[arg(long)]
    repl: bool,

    /// Positional script file (shorthand for --script <file>)
    file: Option<String>,
}
```

Derive `ScriptSource` from `Cli` args:
- `--script <path>` or positional `file` → `ScriptSource::Path`
- `--script -` → `ScriptSource::Stdin`
- `--repl` → force REPL
- No args + terminal stdin → REPL
- No args + piped stdin → `ScriptSource::Stdin`

### 3. Public REPL API (`crates/oxdock-core/src/repl.rs`)

New file. Exposes:

```rust
pub struct ReplSession { /* tempdir, resolver, cwd, envs */ }

impl ReplSession {
    pub fn new(workspace_root: &GuardedPath) -> Result<Self>;
    pub fn run_line(&mut self, input: &str) -> Result<()>;
    pub fn cwd(&self) -> &GuardedPath;
    pub fn into_final_cwd(self) -> GuardedPath;
}
```

`run_line` parses + executes one OxDock command (or multi-line block), accumulating env/cwd state across calls. Uses `ExecState` internally.

Requires making `ExecState`, `execute_steps`, and related types `pub(crate)` or `pub` within `oxdock-core`.

**Key files to modify:**
- `crates/oxdock-core/src/exec/state.rs` — make `ExecState` fields `pub` (or `pub(crate)`)
- `crates/oxdock-core/src/exec/steps.rs` — make `execute_steps` `pub`
- `crates/oxdock-core/src/exec/mod.rs` — make `run_steps_with_fs_with_io` (or equivalent) `pub`
- `crates/oxdock-core/src/lib.rs` — add `pub mod repl;`
- New: `crates/oxdock-core/src/repl.rs`

### 4. REPL loop (`oxdock-cli/src/repl.rs`)

New file. Handles:
- rustyline with prompt `"oxdock> "`
- Multi-line brace accumulation (track `{` / `}` depth, don't execute until balanced)
- `parse_script` + `session.run_line` per chunk
- Error display without backtraces (`{err:#}`)
- `exit` / `quit` / Ctrl-D to leave

### 5. Wire up in `main.rs`

```rust
fn main() {
    let cli = Cli::parse();
    if let Err(err) = oxdock_cli::run(cli) {
        eprintln!("{err:#}");  // Fix: # not ?
        std::process::exit(1);
    }
}
```
