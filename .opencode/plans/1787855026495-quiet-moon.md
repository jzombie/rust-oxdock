# Fix: packaging_invariant test failure on Windows CI

## Problem

`identical_behavior_without_git_or_primary_package` fails because:

1. Generated module contains `include_bytes!` paths with **two** different temp-dir components:
   - `OUT_DIR` (already normalized → `<OUT>`)
   - `CARGO_MANIFEST_DIR` (NOT normalized — different temp dir prefix per run)

2. `GuardedPath::display().to_string()` on Windows produces backslashes (`\`), but generated module code uses forward slashes (`/`) inside `include_bytes!` string literals. The `.replace()` call misses because `\` ≠ `/`.

## Fix

**File:** `oxdock-buildtime-helpers/tests/packaging_invariant.rs`

Use `oxdock_fs::normalized_path()` instead of `.display().to_string()`. `normalized_path` already strips Windows verbatim prefixes and normalizes to forward slashes, so the replacement strings will match the module content.

The out paths (`out_a`, `out_b`) are children of the manifest guards (`with_git`, `without_git`), so they must also be normalized. Since they're constructed via `.join("target-out-a")` on the same guard, we can normalize them via `normalized_path` on the joined path.

### Changes

1. Add `use oxdock_fs::{normalized_path, to_forward_slashes};` to imports (line 12)

2. Change `out_a` / `out_b` construction (lines 66-75) to use `normalized_path`:
```rust
let out_a = normalized_path(
    &with_git.as_guarded_path().join("target-out-a")?
);
let out_b = normalized_path(
    &without_git.as_guarded_path().join("target-out-b")?
);
```

3. Change `run_embed` calls (lines 77-84) to use `normalized_path`:
```rust
let (dirs_a, module_a) = run_embed(
    &normalized_path(with_git.as_guarded_path()),
    &out_a,
)?;
let (dirs_b, module_b) = run_embed(
    &normalized_path(without_git.as_guarded_path()),
    &out_b,
)?;
```

4. Simplify `normalize_module` — replace manual `module.replace('\\', "/")` with `oxdock_fs::to_forward_slashes`:
```rust
use oxdock_fs::to_forward_slashes;

let normalize_module = |module: &str, out: &str, manifest: &str| -> String {
    digits_stripped(
        &to_forward_slashes(module).replace(out, "<OUT>").replace(manifest, "<MANIFEST>"),
    )
};
```

5. Update assertion callers (lines 120-131) to pass the already-normalized strings:
```rust
assert_eq!(
    normalize_module(&module_a, &out_a, &normalized_path(with_git.as_guarded_path())),
    normalize_module(&module_b, &out_b, &normalized_path(without_git.as_guarded_path())),
    "generated modules must be identical after path normalization"
);
```

6. Similarly update `normalize` closure (lines 87-95) and its callers (lines 96-106) to use `normalized_path` instead of `.display().to_string()`.
