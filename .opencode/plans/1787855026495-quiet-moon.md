# Fix: cargo-udeps false positive on oxdock-doc-tests

## Problem

`cargo-udeps` reports `oxdock-buildtime-macros` as an unused dev-dependency of `oxdock-doc-tests`. This is a known false positive — `cargo-udeps` cannot detect usage in doc-tests, which is the sole purpose of this crate.

## Fix

**File:** `crates/oxdock-doc-tests/Cargo.toml`

Add `package.metadata.cargo-udeps.ignore` to suppress the false positive:

```toml
[package.metadata.cargo-udeps.ignore]
development = ["oxdock-buildtime-macros"]
```

## Verification

```
cargo udeps --workspace
```
