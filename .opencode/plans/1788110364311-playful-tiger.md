# Plan: Redesign docs-gen as a Generic Content Composition Engine

## Problem

The current `docs-gen` crate is a single-purpose README builder with hardcoded paths, a hack (`__docs_gen_no_sections__`), and domain-coupled module names. It needs to become a generic content composition tool.

## Architecture

### Module Renames

| Before | After | Role |
|--------|-------|------|
| `doc_runner.rs` | `runner.rs` | Pure step executor — runs `Vec<Step>`, nothing else |
| `sections.rs` | `section_concat.rs` | Concatenates files matching a glob pattern into one output |
| `crate_readme.rs` | `template_doc.rs` | Expands a template with metadata, writes output per member |
| `command_ref.rs` | `command_ref.rs` | Unchanged — generates command reference table |

### Data Flow

```
main.rs (orchestrator — all hardcoded paths live HERE)
  │
  ├── command_ref::generate(output_path)
  │     → writes Markdown table to given path
  │
  ├── section_concat::assemble(repo_root, glob_pattern, output_path, env)
  │     → builds oxdock! steps: GLOB + FOR + READ + APPEND
  │     → calls runner::run()
  │
  └── template_doc::generate_all(repo_root, workspace_toml, template_path, output_name)
        → for each workspace member:
            builds oxdock! steps: INHERIT_ENV + EXPAND + WRITE
            calls runner::run()
```

## File Changes

### 1. `doc_runner.rs` → `runner.rs` — Pure Step Executor

Rename file. Strip all logic except step execution. **No hardcoded paths, no glob, no sections.**

```rust
pub fn run(repo_root: &Path, steps: Vec<Step>, env: ExecIo) -> Result<()> {
    let root = GuardedPath::new_root(repo_root)?;
    run_steps_with_context_result_with_io(&root, &root, &steps, env)?;
    Ok(())
}
```

### 2. `sections.rs` → `section_concat.rs` — Generic Section Concatenation

Rename file. **Accept glob pattern as a parameter.** The function builds its own oxdock! steps:

```rust
/// Concatenate all files matching `glob_pattern` into `output_path`.
pub fn assemble(
    repo_root: &Path,
    glob_pattern: &str,
    output_path: &Path,
    env: ExecIo,
) -> Result<()> {
    let out_str = output_path.display().to_string();
    let pattern_str = glob_pattern.to_string();

    let steps = oxdock! {
        RAW_WRITE #out_str ""
        LET $sections = GLOB(#pattern_str)
        FOR $f IN $sections {
            WITH_IO [stdout=pipe:sec] READ $f
            WITH_IO [stdin=pipe:sec] APPEND #out_str
            APPEND #out_str "\n"
        }
    };

    runner::run(repo_root, steps, env)
}
```

The glob pattern is a parameter — no hardcoded `*.md`. The caller (main.rs) provides the pattern.

### 3. `crate_readme.rs` → `template_doc.rs` — Template Expansion Per Member

Rename file. **Accept all paths as parameters.** The function parses workspace members, expands a template for each, and writes output:

```rust
/// Generate a document for each workspace member by expanding `template_path`
/// with crate metadata. Output files are written to `<member_dir>/<output_name>`.
pub fn generate_all(
    repo_root: &Path,
    workspace_toml: &Path,
    template_path: &Path,
    output_name: &str,
) -> Result<()> {
    let members = parse_workspace_members(workspace_toml)?;

    for member in &members {
        let cargo_toml = repo_root.join(member).join("Cargo.toml");
        if !cargo_toml.exists() {
            continue;
        }
        let out_path = repo_root.join(member).join(output_name);
        if let Err(err) = generate_one(template_path, &cargo_toml, &out_path, repo_root) {
            eprintln!("  Warning: failed to generate {member}/{output_name}: {err:#}");
        }
    }
    Ok(())
}
```

`generate_one` calls `runner::run` directly with template-expansion steps. No dummy directories. No `assemble_doc`.

### 4. `main.rs` — Orchestrator (All Paths Here)

All hardcoded paths live in the orchestrator and are passed as arguments:

```rust
fn main() -> Result<()> {
    let repo_root = find_repo_root()?;

    // Phase 1: command reference
    let cmd_ref_out = repo_root.join("docs/sections/06-command-reference.md");
    command_ref::generate(&cmd_ref_out)?;

    // Phase 2: root README from section files
    let sections_glob = format!("{}/*.md", repo_root.join("docs/sections").display());
    let root_readme = repo_root.join("README.md");
    section_concat::assemble(&repo_root, &sections_glob, &root_readme, ExecIo::new())?;

    // Phase 3: per-crate docs from template
    let template = repo_root.join("docs/templates/crate-readme.md");
    let workspace_toml = repo_root.join("Cargo.toml");
    template_doc::generate_all(&repo_root, &workspace_toml, &template, "README.md")?;

    Ok(())
}
```

### 5. `command_ref.rs` — Unchanged

Already clean. Takes a path, writes content.

## Hardcoded String Audit

| String | Location | Disposition |
|--------|----------|-------------|
| `"*.md"` | Was in `doc_runner.rs` | **Moved to `main.rs`** — caller constructs the glob pattern |
| `"README.md"` | Was in `crate_readme.rs`, `sections.rs` | **Moved to `main.rs`** — caller passes `output_name` / `output_path` |
| `"docs/sections"` | Was in `sections.rs` | **Moved to `main.rs`** — caller passes glob pattern |
| `"docs/templates/crate-readme.md"` | Was in `crate_readme.rs` | **Moved to `main.rs`** — caller passes `template_path` |
| `"__docs_gen_no_sections__"` | Was in `crate_readme.rs` | **Deleted** — no longer needed |
| `"docs/sections/06-command-reference.md"` | `main.rs` | **Retained** — orchestrator config |
| `"workspace"`, `"members"`, `"package"` | `template_doc.rs` | **Retained** — TOML schema constants |
