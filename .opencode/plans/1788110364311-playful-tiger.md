# Plan: Enable #var Interpolation in Guard Brackets

## Problem

`emit_guard_pred` ignores the `_interp` parameter and emits guard keys/values as literal `#key.to_string()`. Placeholders like `__OXDOCK_INJECT_N__` in guard positions are emitted as literal strings instead of being resolved to the Rust variable.

## Root Cause

The `oxdock!` macro's `sanitize_hash_tokens` already replaces `#ident` with `__OXDOCK_INJECT_N__` in the token stream before Pest parsing. The grammar's `env_key` rule (`guard_key_char+`) accepts these placeholders. But `emit_guard_pred` doesn't resolve them.

## Fix

### 1. Add `resolve_placeholder_or_literal` helper

```rust
fn resolve_placeholder_or_literal(
    s: &str,
    interp: &[(proc_macro2::Ident, usize)],
) -> proc_macro2::TokenStream {
    if let Some(idx) = is_placeholder(s) {
        let ident = &interp.iter().find(|(_, i)| *i == idx).unwrap().0;
        quote! { #ident.to_string() }
    } else {
        quote! { #s.to_string() }
    }
}
```

### 2. Update `emit_guard_pred` to use `_interp`

Change `_interp` → `interp` and resolve placeholders in `EnvExists` and `EnvEquals`:

```rust
fn emit_guard_pred(
    g: &oxdock_parser::Guard,
    interp: &[(proc_macro2::Ident, usize)],
) -> proc_macro2::TokenStream {
    match g {
        Guard::Platform { target, invert } => { /* unchanged */ }
        Guard::EnvExists { key, invert } => {
            let k = resolve_placeholder_or_literal(key, interp);
            quote! { Guard::EnvExists { key: #k, invert: #invert } }
        }
        Guard::EnvEquals { key, value, invert } => {
            let k = resolve_placeholder_or_literal(key, interp);
            let v = resolve_placeholder_or_literal(value, interp);
            quote! { Guard::EnvEquals { key: #k, value: #v, invert: #invert } }
        }
    }
}
```

### 3. No grammar changes needed

`env_key` and `env_value` rules already accept `__OXDOCK_INJECT_N__` via `guard_key_char` / `guard_value_char` which allow `_` and digits. `bare_platform` (`ASCII_ALPHANUMERIC+`) doesn't accept placeholders but platform guards don't need runtime interpolation.
