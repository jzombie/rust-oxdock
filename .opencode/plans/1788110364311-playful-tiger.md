# Plan: Eliminate Unquoted Arguments — Enforce Mandatory Quoting

## Context

The grammar has 4 unquoted argument rules (`unquoted_arg`, `unquoted_msg_content`, `unquoted_run_content`, `unquoted_env_value`) that create ambiguity. The ECHO message swallows `IF` keywords. `WRITE $f.txt $i` works via implicit string concatenation. This refactor enforces mandatory quoting for all command arguments, eliminating the entire class of parser ambiguity.

## Files Modified

| File | Change |
|------|--------|
| `crates/oxdock-parser/src/dsl.pest` | Delete `unquoted_*` rules. `argument = { string_literal \| templated_arg }`, `message = { (string_literal \| templated_arg)+ }`, `run_args = { (string_literal \| templated_arg)+ }`, `env_value_part = { string_literal \| templated_arg }` |
| `crates/oxdock-parser/src/parser.rs` | Remove `Rule::unquoted_*` arms from `parse_argument`, `parse_concatenated_string`, `parse_smart_concatenated_string`, `parse_env_pair` |
| `crates/oxdock-parser/src/ast.rs` | No change to `Arg` type (already `Literal`/`Template`) |
| `crates/oxdock-parser/src/macro_input.rs` | Macro step serialization must emit quotes around string arguments and newlines between steps |
| 48 test fixtures | Migrate all unquoted arguments to quoted form |

## Step 1: Grammar — `dsl.pest`

Delete the 4 unquoted rules. Update composite rules to include `expr` for variable/guard support:

```pest
// DELETE: unquoted_arg, unquoted_msg_content, unquoted_run_content, unquoted_env_value

argument = { string_literal | templated_arg | expr }
message = { (string_literal | templated_arg | expr)+ }
run_args = { (string_literal | templated_arg | expr)+ }
env_value_part = { string_literal | templated_arg | expr }
```

`expr` covers `$var`, `$node.path`, key paths, literals, function calls, comparisons, logical ops. `string_literal` covers `"..."` and `'...'`. `templated_arg` covers `{{ env:KEY }}`.

Keep `bare_word` (expressions only), guard rules, `kv_key`, `env_key_part`.

Also fix `if_statement` to use `blank*` (includes linebreaks) for multiline ELSE IF:
```pest
if_statement = { if_keyword ~ expr ~ block ~ (blank* ~ else_if_clause)* ~ blank* ~ else_clause? }
```

## Step 2: Parser — `parser.rs`

Delete `parse_smart_concatenated_string` and `parse_concatenated_string` entirely (dead abstraction after unquoted removal). Update:

- `parse_argument` — remove `Rule::unquoted_arg` arm, keep `quoted_string`, `templated_arg`, add `Rule::expr`
- `parse_env_pair` — remove `Rule::unquoted_env_value` arm
- `parse_run_args` — route directly to argument parsing without smart concatenation
- Message parsing — iterate `string_literal | templated_arg | expr` fragments directly

## Step 3: Macro — `macro_input.rs` + `lib.rs`

**Problem:** The `oxdock!` macro puts consecutive statements on the same line (`ECHO "..." IF ...`), causing ECHO to consume the IF keyword.

**Fix:** In `script_from_braced_tokens`, emit `\n` after block-end tokens (`}` from `Delimiter::Brace` groups that aren't interpolation or template contexts). When the walker finalizes a line containing a closing `}`, push a newline before the next token. This uses structural block boundaries — not keyword matching — to separate statements.

## Step 4: Migrate 48 Test Fixtures

Every `.oxdock` script needs quoted arguments:
- `WRITE note.txt hello` → `WRITE "note.txt" "hello"`
- `ECHO hello` → `ECHO "hello"`
- `RUN echo hi` → `RUN "echo hi"`
- `ENV FOO=bar` → `ENV FOO="bar"`
- `WRITE $f.txt $f` → `WRITE "$f.txt" "$f"`
- Paths: `note.txt` → `"note.txt"`, `./source.txt` → `"./source.txt"`

## Step 5: Migration Script

Write a helper to bulk-migrate fixtures, or migrate manually with search-and-replace patterns.
