# Plan: Docker-Style Default Expansion + Delete RAW_WRITE

## Context

All strings expand by default. `\$` → literal `$`, `\{{` → literal `{{`. Delete `RAW_WRITE`.

**Escape rules:**
- `\\` → literal `\`
- `\$` → literal `$`, skips variable lookup
- `\{{` → literal `{{`, skips template expansion
- All other `$` and `{{` expand normally

**Single source of truth:** ALL backslash processing happens in one place — `expand_string` at runtime. The parser passes string contents verbatim (no escape stripping).

## Step 4: Single-Pass Expansion — `args.rs`

Replace `resolve_dollar_vars` + `StreamingExpand` with unified `expand_string`:

```rust
pub(crate) fn expand_string(input: &str, state: &ExecState) -> String {
    let mut output = String::new();
    let mut chars = input.chars().peekable();
    while let Some(c) = chars.next() {
        match c {
            '\\' => match chars.peek() {
                Some(&'\\') => { output.push('\\'); chars.next(); }
                Some(&'$') => { output.push('$'); chars.next(); }
                Some(&'n') => { output.push('\n'); chars.next(); }
                Some(&'t') => { output.push('\t'); chars.next(); }
                Some(&'r') => { output.push('\r'); chars.next(); }
                Some(&'"') => { output.push('"'); chars.next(); }
                Some(&'{') if chars.clone().nth(1) == Some('{') => {
                    output.push_str("{{"); chars.next(); chars.next();
                }
                _ => output.push('\\'),
            },
            '$' => { /* collect variable name, look up, emit value */ }
            '{' if chars.peek() == Some(&'{') => {
                chars.next();
                /* collect until }}), expand env:KEY */
            }
            _ => output.push(c),
        }
    }
    output
}
```

`resolve_arg_state`:
```rust
Arg::String(s) => Ok(expand_string(s, state)),
Arg::Expr(e) => { let v = evaluate_expr(e, state)?; Ok(format_value_for_string(&v)) }
```

Delete `StreamingExpand` from `expand.rs` (or keep for backward compat but unused).

## Step 5: Delete RAW_WRITE

Remove from: `handlers.rs`, `steps.rs`, `lib.rs`, `track.rs`, grammar.

## Step 6: Macro Token Unescaping — `macro_input.rs`

Use `syn::LitStr::value()` to unescape string tokens. This lets Rust's compiler handle `\\$` → `\$` correctly. Do NOT manual-replace strings.

## Step 7: Migrate

- `RAW_WRITE "file" "content"` → `WRITE "file" "content"` (expands — escape if needed)
- `RAW_WRITE "file" "hello {{ env:USER }}"` → `WRITE "file" "hello \{{ env:USER }}"`
- `WRITE "file" "price is $5.00"` → `WRITE "file" "price is \$5.00"`
- In `oxdock!` blocks: `WRITE "file" "price is \\$5.00"` (double backslash for Rust)
