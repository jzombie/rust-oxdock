# Plan: Eliminate Rust Glue in docs-gen via Native DSL Pipeline

## Context

`docs-gen/src/template_doc.rs` currently uses Rust `for` loops, a `match` statement, and a `DocNode` enum to manually assemble Oxdock steps via 4+ `oxdock!` macro invocations. The DSL engine now has `LOAD_JSON`, `FOR`, `IF/ELSE`, key-path traversal, and all required commands (`RAW_WRITE`, `APPEND`, `EXPAND`, `READ`, `WITH_IO` pipes). No new DSL features are needed — the entire control flow can move into a single embedded `oxdock!` block.

**Problem:** The manifest is constructed dynamically at runtime by reading workspace `Cargo.toml` files and computing glob patterns. It cannot be a static JSON file on disk — it must be generated by Rust and passed to the DSL.

**Solution:** Rust generates the manifest JSON string, writes it to a staging directory inside `repo_root` (sandbox-safe), then invokes a single `oxdock!` block that loads the manifest via `LOAD_JSON` and processes it with native `FOR`/`IF/ELSE`. The `DocNode` enum and Rust `match` logic are deleted entirely.

## Files Modified

| File | Change |
|------|--------|

## Step 1: Rewrite `template_doc.rs`

Delete `DocNode` enum. Rewrite `compile` to accept a JSON manifest string, write it to a staging directory inside the sandbox, and invoke a single `oxdock!` block:

```rust
use anyhow::Result;
use oxdock_core::ExecIo;
use oxdock_fs::GuardedPath;
use oxdock_macros::oxdock;
#[allow(clippy::disallowed_types)]
use std::path::Path;

use crate::runner;

#[allow(clippy::disallowed_types, clippy::disallowed_methods)]
pub fn compile(
    repo_root: &Path,
    manifest_json: &str,
    output_path: &Path,
    env: ExecIo,
) -> Result<()> {
    let root = GuardedPath::new_root(repo_root)?;
    let staging_dir = root.join(".oxdock-staging")?;
    std::fs::create_dir_all(staging_dir.as_path())?;

    let manifest_file = staging_dir.join("docs_manifest.json")?;
    std::fs::write(manifest_file.as_path(), manifest_json)?;

    let manifest_str = manifest_file.as_path().display().to_string();
    let out_str = output_path.display().to_string();

    let steps = oxdock! {
        RAW_WRITE #out_str ""
        LET $manifest = LOAD_JSON(#manifest_str)

        FOR $node IN $manifest {
            IF $node.kind == "template" {
                WITH_IO [stdout=pipe:tmpl] EXPAND $node.path
                WITH_IO [stdin=pipe:tmpl] APPEND #out_str
            } ELSE IF $node.kind == "glob" {
                LET $sections = GLOB($node.pattern)
                FOR $f IN $sections {
                    WITH_IO [stdout=pipe:sec] READ $f
                    WITH_IO [stdin=pipe:sec] APPEND #out_str
                    APPEND #out_str "\n"
                }
            } ELSE IF $node.kind == "raw" {
                APPEND #out_str $node.text
            }
        }
    };

    let res = runner::run(repo_root, steps, env);
    let _ = std::fs::remove_file(manifest_file.as_path());
    res
}
```

**Key details:**
- `GuardedPath::new_root(repo_root)` creates a guarded root at the repo (`path.rs:63`).
- `root.join(".oxdock-staging")` creates a guarded child path inside the sandbox (`path.rs:180`).
- `staging_dir.join("docs_manifest.json")` creates the manifest file path inside the staging dir.
- `manifest_file.as_path()` returns `&Path` for `std::fs::write` (`path.rs:149`).
- The manifest path is inside `repo_root`, so `LOAD_JSON` resolves it within the sandbox boundary.
- Cleanup: `std::fs::remove_file` removes the staging file after `runner::run` completes.
- Single `oxdock!` block replaces 4 separate macro invocations + Rust `for`/`match`.

## Step 2: Rewrite `main.rs` to Build Manifest JSON

The `generate_crate_docs` function currently builds `Vec<DocNode>`. Rewrite it to build a JSON array string and pass it to `compile`. Use workspace-relative glob patterns (not absolute paths):

```rust
fn generate_crate_docs(repo_root: &Path, template_dir: &Path) -> Result<()> {
    let workspace_toml = repo_root.join("Cargo.toml");
    let members = parse_workspace_members(&workspace_toml)?;

    let header = template_dir.join("crate-header.md");
    let footer = template_dir.join("crate-footer.md");

    if !header.exists() || !footer.exists() {
        eprintln!("Skipping crate docs: templates not found at {}", template_dir.display());
        return Ok(());
    }

    let header_str = header.display().to_string();
    let footer_str = footer.display().to_string();

    for member in &members {
        let member_cargo_toml = repo_root.join(member).join("Cargo.toml");
        if !member_cargo_toml.exists() {
            eprintln!("Skipping {member}: no Cargo.toml found");
            continue;
        }

        let meta = parse_cargo_metadata(&member_cargo_toml)?;
        let mut env = ExecIo::new();
        env.set("CRATE_NAME", &meta.name);
        env.set("CRATE_DESCRIPTION", &meta.description);

        // Workspace-relative glob pattern (not absolute)
        let glob = format!("docs/crates/{}/*.md", meta.name);

        // Build manifest as JSON array
        let manifest = serde_json::json!([
            { "kind": "template", "path": header_str },
            { "kind": "glob", "pattern": glob },
            { "kind": "template", "path": footer_str }
        ]);
        let manifest_json = manifest.to_string();

        let out_path = repo_root.join(member).join("README.md");
        if let Err(err) = template_doc::compile(repo_root, &manifest_json, &out_path, env) {
            eprintln!("  Warning: failed to generate {member}/README.md: {err:#}");
        }
    }

    Ok(())
}
```
