# Plan: Add `LOAD_TOML` / `LOAD_JSON` + Key-Path Expressions

## Goal

Make Oxdock DSL own document composition natively by adding format-agnostic data loading primitives (`LOAD_TOML`, `LOAD_JSON`) and key-path expressions (`$pkg.package.name`). This eliminates the Rust orchestration layer in `docs-gen` — a single `.oxdock` script reads `Cargo.toml`, iterates workspace members, and composes READMEs.

## Target Script

```text
LET $workspace = LOAD_TOML("Cargo.toml")

FOR $member IN $workspace.workspace.members {
    LET $pkg = LOAD_TOML($member + "/Cargo.toml")
    LET $name = $pkg.package.name
    LET $desc = $pkg.package.description
    LET $out = $member + "/README.md"
    LET $sections = GLOB("docs/crates/" + $name + "/*.md")

    RAW_WRITE $out ""
    EXPAND "docs/templates/crate-header.md" -> APPEND $out
    FOR $f IN $sections {
        READ $f -> APPEND $out
        APPEND $out "\n"
    }
    EXPAND "docs/templates/crate-footer.md" -> APPEND $out
}
```

## Phase 1: AST Types

### 1.1 Refactor `Value::List` to hold generic values + add `Value::Map` with BTreeMap

**File:** `crates/oxdock-parser/src/ast.rs`

```rust
pub enum Value {
    String(String),
    List(Vec<Value>),   // CHANGED: Vec<String> → Vec<Value>
    Map(std::collections::BTreeMap<String, Value>),  // NEW — BTreeMap for deterministic ordering
    Bool(bool),
}
```

`Value::List` must hold `Vec<Value>` to support heterogeneous arrays (e.g., `[[bin]]` in TOML, arrays of objects in JSON). `BTreeMap` (not `HashMap`) ensures deterministic key ordering across runs — `HashMap` uses random sip-hash seeding, producing non-deterministic output for stringification, macro code generation, and document streams.

## Phase 2: Grammar + Parser

### 2.1 Add `key_path` PEG rule with underscore + numeric support

**File:** `crates/oxdock-parser/src/dsl.pest`

```pest
key_path_segment = @{ (ASCII_ALPHA | "_") ~ (ASCII_ALPHANUMERIC | "_")* | ASCII_DIGIT+ }
key_path         = { "$" ~ ident ~ ("." ~ key_path_segment)+ }
```

Update `expr` rule to try `key_path` before `variable`:

```pest
expr = { func_call | key_path | variable | list_literal | string_literal | bare_word }
```

Order matters — `key_path` must precede `variable` so `$pkg.package.name` isn't split at `$pkg`. Underscore-prefixed segments (`$data._links`) are allowed. Numeric segments support array indexing (`$pkg.authors.0`).

## Phase 3: Expression Evaluation

### 3.1 Add `KeyPath` evaluation with array index support

**File:** `crates/oxdock-core/src/exec/args.rs`

New match arm in `evaluate_expr`:

```rust
Expr::KeyPath { base, keys } => {
    let mut current = cx.state.get_var(base)?;
    for key in keys {
        match current {
            Value::Map(map) => {
                current = map.get(key).cloned().ok_or_else(|| {
                    ExecError::KeyNotFound(format!("Key '{key}' not found"))
                })?;
            }
            Value::List(list) => {
                let idx: usize = key.parse().map_err(|_| {
                    ExecError::InvalidIndex(format!("Invalid index '{key}'"))
                })?;
                current = list.get(idx).cloned().ok_or_else(|| {
                    ExecError::IndexOutOfBounds(format!("Index {idx} out of bounds"))
                })?;
            }
            Value::String(_) | Value::Bool(_) => {
                return Err(ExecError::InvalidTraversal(
                    format!("Cannot traverse into scalar value at key '{key}'")
                ));
            }
        }
    }
    Ok(current)
}
```

### 3.4 Add JSON → `Value` conversion helper

**File:** `crates/oxdock-core/src/exec/args.rs`

```rust
fn json_to_value(v: serde_json::Value) -> Value {
    match v {
        serde_json::Value::String(s) => Value::String(s),
        serde_json::Value::Bool(b) => Value::Bool(b),
        serde_json::Value::Number(n) => Value::String(n.to_string()),
        serde_json::Value::Array(arr) => Value::List(arr.into_iter().map(json_to_value).collect()),
        serde_json::Value::Object(map) => Value::Map(
            map.into_iter().collect()  // BTreeMap — already sorted by key
        ),
        serde_json::Value::Null => Value::String(String::new()),
    }
}
```

TOML goes through `toml::from_str::<serde_json::Value>` first, then uses the same `json_to_value` converter. No separate `toml_to_value` needed. Explicit `Bool` arm ensures `Value::Bool` is reachable during deserialization.

### 3.5 Fix `resolve_dollar_vars` — stop traversal at scalar values

**File:** `crates/oxdock-core/src/exec/args.rs`

Critical fix: key-path traversal in string literals must stop consuming dot-segments as soon as a scalar is reached. Without this, `"docs/$pkg.name.md"` consumes `.md` as a key, fails lookup, and falls back to raw unexpanded text.

```rust
pub(crate) fn resolve_dollar_vars<P: ProcessManager>(
    input: &str,
    state: &ExecState<P>,
) -> String {
    let mut result = String::new();
    let mut chars = input.chars().peekable();
    while let Some(c) = chars.next() {
        if c == '$' {
            // Collect base identifier
            let mut name = String::new();
            while let Some(&ch) = chars.peek() {
                if ch.is_alphanumeric() || ch == '_' {
                    name.push(ch);
                    chars.next();
                } else {
                    break;
                }
            }
            if name.is_empty() {
                result.push('$');
                continue;
            }
            // Attempt key-path traversal, stopping at scalar values
            let mut current = match state.get_var(&name) {
                Some(v) => v,
                None => {
                    // Fall back to environment variables for ambient env lookups
                    if let Some(env_val) = state.envs.get(&name) {
                        Value::String(env_val.clone())
                    } else {
                        result.push('$');
                        result.push_str(&name);
                        continue;
                    }
                }
            };
            let mut consumed_keys = Vec::new();
            loop {
                if chars.peek() != Some(&'.') {
                    break;
                }
                // Peek ahead: collect the segment without consuming
                let mut temp_chars = chars.clone();
                temp_chars.next(); // consume '.'
                let mut segment = String::new();
                while let Some(&ch) = temp_chars.peek() {
                    if ch.is_alphanumeric() || ch == '_' {
                        segment.push(ch);
                        temp_chars.next();
                    } else {
                        break;
                    }
                }
                if segment.is_empty() {
                    break;
                }
                // Try to traverse into current value
                match &current {
                    Value::Map(map) => {
                        if let Some(next) = map.get(&segment) {
                            current = next.clone();
                            consumed_keys.push(segment);
                            chars = temp_chars; // commit consumption
                        } else {
                            break; // key not found — trailing text is literal
                        }
                    }
                    Value::List(list) => {
                        if let Ok(idx) = segment.parse::<usize>() {
                            if let Some(next) = list.get(idx) {
                                current = next.clone();
                                consumed_keys.push(segment);
                                chars = temp_chars;
                            } else {
                                break;
                            }
                        } else {
                            break; // not an index — trailing text is literal
                        }
                    }
                    Value::String(_) | Value::Bool(_) => {
                        break; // reached scalar — trailing dots are literal text
                    }
                }
            }
            result.push_str(&format_value_for_string(&current));
        } else {
            result.push(c);
        }
    }
    result
}
```

### 3.6 Add `format_value_for_string` helper

```rust
fn format_value_for_string(val: &Value) -> String {
    match val {
        Value::String(s) => s.clone(),
        Value::Bool(b) => b.to_string(),
        Value::List(items) => {
            items.iter()
                .map(|v| format_value_for_string(v))
                .collect::<Vec<_>>()
                .join(" ")
        }
        Value::Map(map) => {
            // Serialize map as JSON string for inline interpolation
            map.iter()
                .map(|(k, v)| format!("\"{}\": {}", k, format_value_for_string(v)))
                .collect::<Vec<_>>()
                .join(", ")
        }
    }
}
```

### 3.7 Update `FOR` loop handler for `Value::List(Vec<Value>)`

**File:** `crates/oxdock-core/src/exec/handlers.rs`

Phase 1.1 changed `Value::List` from `Vec<String>` to `Vec<Value>`. The `FOR` loop handler must bind each `Value` item directly to `ExecState.vars` instead of wrapping strings:

```rust
pub(super) fn for_loop<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    var: &str,
    in_expr: &Expr,
    body: &[Step],
) -> Result<()> {
    let iterable = super::args::evaluate_expr(in_expr, cx)?;
    let clean_var = var.trim_start_matches('$').to_string();

    if let Value::List(items) = iterable {
        for item in items {
            cx.state.push_var_scope();
            // Bind the Value directly — no wrapping in Value::String
            cx.state.set_var(clean_var.clone(), item);

            let saved_cwd = cx.state.cwd.clone();
            let saved_root = cx.state.fs.root().clone();
            let saved_envs = Arc::clone(&cx.state.envs);

            let res = super::steps::execute_steps(
                cx.state, cx.process, body, cx.stdin.clone(),
                false, cx.out.clone(), cx.err.clone(), false,
            );

            cx.state.cwd = saved_cwd;
            cx.state.fs.set_root(&saved_root);
            cx.state.envs = saved_envs;
            cx.state.pop_var_scope();
            res?;
        }
        Ok(())
    } else {
        bail!("FOR loop requires a list iterable")
    }
}
```

## Phase 4: EXPAND — Single-Pass Tag Evaluation

**File:** `crates/oxdock-core/src/exec/handlers.rs`

### 4.1 Replace two-pass pre-expansion with single-pass tag resolver

Two-pass pre-expansion (Option A from previous plan) causes double-expansion: if a resolved variable contains `{{ env:SECRET }}`, the second `StreamingExpand` pass evaluates injected tags, breaking template boundary isolation.

**Solution:** Single-pass evaluation. Modify the `EXPAND` handler to evaluate ALL tags in one traversal using a unified tag resolver that handles both `{{ env:KEY }}` and `{{ pkg.package.name }}`:

```rust
pub fn resolve_template_tag(tag: &str, state: &ExecState) -> Result<String> {
    let trimmed = tag.trim();
    // Strip optional "env:" prefix for backward compat
    let key = trimmed.strip_prefix("env:").unwrap_or(trimmed);
    if key.contains('.') {
        // Key-path traversal against structured vars
        let parts: Vec<&str> = key.split('.').collect();
        let base = parts[0];
        let keys: Vec<String> = parts[1..].iter().map(|s| s.to_string()).collect();
        let val = resolve_key_path_from_state(base, &keys, state)?;
        Ok(format_value_for_string(&val))
    } else {
        // Simple variable or env lookup
        if let Some(val) = state.get_var(key) {
            Ok(format_value_for_string(&val))
        } else if let Some(env_val) = state.envs.get(key) {
            Ok(env_val.clone())
        } else {
            bail!("Template tag '{}' not found in scope", key)
        }
    }
}
```

Wire this into `StreamingExpand` (or replace it) so tag evaluation happens in a single pass over the template content.
