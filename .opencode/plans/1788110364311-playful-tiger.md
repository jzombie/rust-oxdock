# Plan: Make template_doc.rs Generic

## Problem

`template_doc.rs` parses `Cargo.toml`, extracts `package.name`/`package.description`, and iterates `workspace.members`. This forces the tool to be Rust-specific.

## Solution

### 1. `template_doc.rs` — Pure template expansion, zero Cargo awareness

```rust
pub fn expand(repo_root, template_path, output_path, env: ExecIo) -> Result<()>
pub fn expand_glob(repo_root, template_path, dir_glob, output_name, base_env: ExecIo) -> Result<()>
```

No `CargoMetadata`. No `parse_cargo_metadata`. No `parse_workspace_members`. No `toml_edit`.

### 2. `main.rs` — Owns all Rust-specific knowledge

```rust
fn main() -> Result<()> {
    // Phase 3: per-crate docs from template
    let template = repo_root.join("docs/templates/crate-readme.md");
    let workspace_toml = repo_root.join("Cargo.toml");
    let members = parse_workspace_members(&workspace_toml)?;

    for member in &members {
        let cargo_toml = repo_root.join(member).join("Cargo.toml");
        if !cargo_toml.exists() { continue; }

        let meta = parse_cargo_metadata(&cargo_toml)?;
        let mut env = ExecIo::new();
        env.insert_inherit_env("CRATE_NAME", &meta.name);
        env.insert_inherit_env("CRATE_DESCRIPTION", &meta.description);

        let out_path = repo_root.join(member).join("README.md");
        template_doc::expand(&repo_root, &template, &out_path, env)?;
    }
}
```

`parse_workspace_members` and `parse_cargo_metadata` move to `main.rs`.

### 3. `Cargo.toml` — Add `glob` dependency

```toml
glob.workspace = true
```

Workspace root already has `glob = "0.3"`.

## Files Modified

| File | Change |
|------|--------|
| `crates/docs-gen/src/template_doc.rs` | Strip to `expand` + `expand_glob`, no Cargo.toml parsing |
| `crates/docs-gen/src/main.rs` | Add `parse_workspace_members`, `parse_cargo_metadata`, `CargoMetadata` |
| `crates/docs-gen/Cargo.toml` | Add `glob.workspace = true` |

## Verification

1. `cargo check -p docs-gen`
2. `cargo run -p docs-gen` — same output as before
3. `git diff` — no content loss in READMEs
