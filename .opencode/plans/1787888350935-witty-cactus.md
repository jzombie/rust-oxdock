# Plan: Streaming Template Engine + REPLACE Command

## Goal

Replace the string-based template expansion (`expand_with_lookup`) with a streaming `StreamingExpand` state machine. No command in the DSL should ever buffer large content. Add a `REPLACE` command that uses this streaming infrastructure to expand file/stdin content with `{{ env:KEY }}` placeholders.

This is a full refactor — no deprecation, no legacy APIs. Alpha software, clean break.

## Scope

### Part 1: Streaming Template Engine

Replace the entire expansion subsystem:

| Current | Replacement |
|---|---|
| `expand_with_lookup(input: &str) -> String` | `StreamingExpand::process_bytes(input: &[u8], out: &mut Vec<u8>)` |
| `expand_script_env(input: &str) -> String` | `StreamingExpand::new(overrides, script_envs)` |
| `expand_command_env(input: &str) -> String` | `StreamingExpand::new(overrides, ctx.envs())` |
| `expand_template(t, ctx) -> String` | `StreamingExpand::new(overrides, ctx.envs())` |

**New API in `crates/sys/oxdock-process/src/expand.rs`:**

```rust
/// Maximum bytes to buffer while scanning for `}}` closing.
/// If exceeded without finding `}}`, buffered bytes are flushed as literals.
const MAX_PLACEHOLDER_SCAN: usize = 1024;

pub struct StreamingExpand {
    /// Bytes accumulated while scanning for `}}` inside a placeholder.
    buffer: Vec<u8>,
    /// Explicit key=value overrides (take precedence over env).
    overrides: HashMap<String, String>,
    /// Environment variable lookup.
    env: HashMap<String, String>,
    /// State: are we currently inside a `{{ ... }}` placeholder?
    in_placeholder: bool,
    /// Trailing `{` from previous chunk — deferred to next `process_bytes` call.
    /// Handles the case where a chunk ends on a single `{` and the next chunk
    /// starts with `{`, forming `{{` across the boundary.
    pending_brace: bool,
}

impl StreamingExpand {
    /// Create with env vars and optional explicit overrides.
    /// Overrides take precedence over env vars.
    pub fn new(
        overrides: &[(String, String)],
        env: &HashMap<String, String>,
    ) -> Self;

    /// Process a chunk of input bytes, writing expanded output to `out`.
    /// Handles partial `{{ env:KEY }}` across chunk boundaries.
    /// Returns the number of bytes written to `out`.
    pub fn process_bytes(&mut self, input: &[u8], out: &mut Vec<u8>) -> Result<usize>;

    /// Flush remaining buffer. Incomplete placeholders are treated as literals.
    pub fn flush(mut self, out: &mut Vec<u8>) -> Result<()>;

    /// Process a complete string (convenience for short command arguments).
    pub fn expand_string(self, input: &str) -> Result<String>;
}
```

**State machine for `process_bytes` — immediate flush guarantee:**

The key insight: bytes that are guaranteed to never be part of a placeholder are flushed immediately. Only bytes that *might* be part of `{{ ... }}` are buffered. The `buffer` holds ONLY the key payload (inside `{{ }}`), never the `{{` prefix itself.

```
State: Normal
  - Scan for `{`
  - Everything before `{` → flush to `out` immediately
  - If `{` found at position i:
    - If i+1 < len and input[i+1] == `{`:
      - Set in_placeholder = true, clear buffer, skip both `{`
      - Continue scanning from i+2 for key content
    - If `{` is the LAST byte of chunk:
      - Set pending_brace = true, do NOT flush yet
      - Continue to next chunk
    - Else: flush `{` to `out`, continue Normal

State: PlaceholderScan (inside `{{`)
  - Scan for `}}`
  - If found: extract key from buffer, lookup value, flush expansion to `out`, return to Normal
  - If buffer exceeds MAX_PLACEHOLDER_SCAN (1024 bytes) without `}}`:
    - Flush `{{` + buffer as literal text to `out` (exactly ONE `{{` prefix)
    - Reset buffer, set in_placeholder = false, return to Normal
  - If chunk ends without `}}`: keep in buffer, continue PlaceholderScan
```

**pending_brace evaluation (zero-allocation):**
```rust
if self.pending_brace {
    self.pending_brace = false;
    if !input.is_empty() && input[0] == b'{' {
        // Confirmed `{{` across boundary — enter PlaceholderScan
        self.in_placeholder = true;
        self.buffer.clear();
        start = 1; // Skip the second `{`, continue scanning from input[1..]
    } else {
        // Single `{` was just a literal — flush it
        out.push(b'{');
        start = 0; // Process input[0..] normally
    }
}
```

**flush() behavior:**
```rust
fn flush(mut self, out: &mut Vec<u8>) -> Result<()> {
    // Emit pending single `{` if present
    if self.pending_brace {
        out.push(b'{');
        self.pending_brace = false;
    }
    // If inside placeholder, emit `{{` prefix ONCE before buffer
    if self.in_placeholder {
        out.extend_from_slice(b"{{");
        self.in_placeholder = false;
    }
    // Flush remaining buffer as literal text
    out.extend_from_slice(&self.buffer);
    self.buffer.clear();
    Ok(())
}
```

**Critical property:** At most `MAX_PLACEHOLDER_SCAN` bytes are ever held in buffer. Plain text streams flush immediately with zero buffering. A trailing `{` is deferred (1 byte) until the next chunk confirms or denies `{{`. Unclosed/overlong placeholders emit exactly one `{{` prefix, not two.

**Helper functions (private):**
- `extract_key(placeholder: &[u8]) -> Result<String>` — extract and trim key from buffer content
- `lookup(raw_key: &str, overrides: &HashMap, env: &HashMap) -> String` — strip namespace prefix, resolve with override precedence

```rust
fn lookup(raw_key: &str, overrides: &HashMap<String, String>, env: &HashMap<String, String>) -> String {
    let key = raw_key.trim();
    // Strip namespace prefix for override matching
    // {{ env:CRATE_NAME }} or {{ script_env:CRATE_NAME }} → lookup "CRATE_NAME"
    let normalized = key
        .strip_prefix("env:")
        .or_else(|| key.strip_prefix("script_env:"))
        .unwrap_or(key);

    // Check overrides with both raw and normalized keys
    overrides
        .get(key)
        .or_else(|| overrides.get(normalized))
        // Fall back to env with normalized key
        .or_else(|| env.get(normalized))
        .cloned()
        .unwrap_or_default()
}
```

### Part 3: Add REPLACE Command

**Grammar (`crates/oxdock-parser/src/dsl.pest`):**

```pest
replace_command = ${ "REPLACE" ~ (sep ~ !(argument ~ "=") ~ argument)? ~ (sep ~ key_value)* }
key_value = ${ argument ~ "=" ~ argument }
```

The negative lookahead `!(argument ~ "=")` prevents `REPLACE FOO=BAR` from parsing `FOO=BAR` as a file path. It ensures the optional path argument is only matched when it's NOT a key-value pair.

**AST (`crates/oxdock-parser/src/ast.rs`):**

```rust
Replace {
    path: Option<TemplateString>,
    overrides: Vec<(String, TemplateString)>,
},
```

**Handler (`crates/oxdock-core/src/exec/handlers.rs`):**

```rust
pub(super) fn replace<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    idx: usize,
    path_opt: &Option<TemplateString>,
    overrides: &[(String, TemplateString)],
) -> Result<()> {
    let ctx = cx.state.command_ctx()?;

    // Resolve override values
    let resolved_overrides: Vec<(String, String)> = overrides
        .iter()
        .map(|(k, v)| (k.clone(), expand_template_string(v, &ctx)))
        .collect();

    let mut expander = StreamingExpand::new(&resolved_overrides, &ctx.envs());
    let mut out_buf = Vec::with_capacity(8192);

    write_stdout(cx.out.clone(), |w| {
        if let Some(path) = path_opt {
            // Streaming file read
            let rendered = expand_template_string(path, &ctx);
            let target = cx.state.fs.resolve_read(&cx.state.cwd, &rendered)
                .with_context(|| format!("step {}: REPLACE {}", idx + 1, rendered))?;
            let mut reader = cx.state.fs.open_read(&target)
                .with_context(|| format!("failed to open {}", target.display()))?;
            let mut buf = [0u8; 8192];
            loop {
                let n = reader.read(&mut buf)
                    .with_context(|| format!("failed to read {}", target.display()))?;
                if n == 0 { break; }
                expander.process_bytes(&buf[..n], &mut out_buf)?;
                w.write_all(&out_buf)
                    .context("failed to write output")?;
                out_buf.clear();
            }
        } else {
            // Streaming stdin — error if no stdin available
            let Some(input_stream) = cx.stdin.clone() else {
                bail!(
                    "step {}: REPLACE requires stdin when no file path is given \
                     (use WITH_IO [stdin=...] REPLACE)",
                    idx + 1
                );
            };
            let mut guard = input_stream.lock()
                .map_err(|_| anyhow!("failed to lock stdin for REPLACE"))?;
            let mut buf = [0u8; 8192];
            loop {
                let n = guard.read(&mut buf)
                    .context("failed to read from stdin")?;
                if n == 0 { break; }
                expander.process_bytes(&buf[..n], &mut out_buf)?;
                w.write_all(&out_buf)
                    .context("failed to write output")?;
                out_buf.clear();
            }
        }

        // Flush remaining buffer (incomplete placeholders → literals)
        expander.flush(&mut out_buf)?;
        if !out_buf.is_empty() {
            w.write_all(&out_buf)
                .context("failed to write output")?;
            out_buf.clear();
        }

        Ok(())
    })?;

    Ok(())
}
```

**Key handler properties:**
1. **Mandatory stdin error**: `bail!` when no path and no stdin
2. **Streaming output**: `out_buf` is written and cleared after every chunk — O(1) memory
3. **Single lock acquisition**: `write_stdout` wraps the entire loop — one lock/unlock cycle
4. **No allocation per chunk**: `process_bytes` writes into `&mut out_buf`, reuses capacity

## Example Workflow

```oxdock
ENV CRATE_NAME=oxdock-fs
ENV CRATE_DESC="Filesystem abstractions"

# Stream expanded template to a file
WITH_IO [stdout=pipe:tmpl] REPLACE template.md
WITH_IO [stdin=pipe:tmpl] WRITE crates/oxdock-fs/README.md

# Use explicit overrides instead of env (file path + overrides)
WITH_IO [stdout=pipe:tmpl] REPLACE template.md CRATE_NAME=oxdock-core TITLE="Core"
WITH_IO [stdin=pipe:tmpl] WRITE crates/oxdock-core/README.md

# Stdin mode with overrides (no file path)
WITH_IO [stdout=pipe:tmpl] WRITE template.md "Hello {{ env:NAME }}"
WITH_IO [stdout=pipe:tmpl] REPLACE NAME=World
WITH_IO [stdin=pipe:tmpl] WRITE output.md

# Conditional sections
[env:DEBUG]
WITH_IO [stdout=pipe:tmpl] REPLACE debug-section.md
WITH_IO [stdin=pipe:tmpl] APPEND output.md

# Verify
ASSERT_FILE crates/oxdock-fs/README.md "# oxdock-fs\n\nFilesystem abstractions"
```
