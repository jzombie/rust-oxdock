# Plan: Stream-Native Pipeline Architecture — Amendment

## Goal

Make every I/O handler in the DSL operate in O(1) memory with 8KB fixed buffers. No handler waits for EOF before emitting data or yielding control. Data flows through `REPLACE`, `WRITE`, `HASH_SHA256`, and process pipes chunk-by-chunk without a single EOF bottleneck.

## Architectural Invariants

1. **Standardized 8 KB Chunk Loop** — All handlers taking stdin input operate on a fixed stack buffer `[u8; 8192]`. Each cycle calls `writer.write_all(&buf[..n])` and `writer.flush()`.
2. **Automatic Stream Teeing** — Passive handlers (`HASH_SHA256`, `ASSERT_STDOUT`) act as non-blocking observers. Incoming chunks are written to `cx.out` while simultaneously updating internal state.
3. **Sliding Window** — `ASSERT_STDOUT` maintains a ring buffer of size `needle.len()`. Match is detected inline as chunks pass through.
4. **AST Metadata Isolation** — Control metadata (`WORKDIR`, `ENV`, command paths) executes synchronously against short AST strings prior to step launch, outside active I/O pipes.

## Critical Flaw Fixes (Amendment)

### Fix 1: Split Closing Delimiter (`}}`) in StreamingExpand

**Problem:** When `}}` is split across chunk boundaries (`}` at end of chunk N, `}` at start of chunk N+1), `scan_placeholder` pushes the trailing `}` into the buffer as part of the key, and the leading `}` of the next chunk fails the two-byte lookahead. The state machine stays in `PlaceholderScan`, corrupting output.

**Also:** `flush()` must emit `pending_close_brace` as a literal `}` when the stream ends with a deferred closing brace.

**Fix:** Add `pending_close_brace: bool` to `StreamingExpand`. When a chunk ends with `}` while in PlaceholderScan, set the flag instead of pushing to buffer.

```rust
pub struct StreamingExpand {
    buffer: Vec<u8>,
    overrides: HashMap<String, String>,
    env: HashMap<String, String>,
    in_placeholder: bool,
    pending_brace: bool,        // Trailing `{` deferred across chunks
    pending_close_brace: bool,  // Trailing `}` deferred across chunks
}
```

**In `scan_placeholder`** — when `i == input.len() - 1` and `input[i] == self.delimiters.close[0]`:
```rust
if i + 1 >= input.len() {
    // Last byte is closing byte — might be start of close delimiter across boundary
    self.pending_close_brace = true;
    return i + 1;
}
```

**In `process_bytes`** — at the start, before other checks:
```rust
if self.pending_close_brace {
    self.pending_close_brace = false;
    if !input.is_empty() && input[0] == self.delimiters.close[1] {
        // Confirmed close delimiter across boundary — extract key, lookup, emit
        let key = extract_key(&self.buffer);
        let value = lookup(&key, &self.overrides, &self.env);
        out.extend_from_slice(value.as_bytes());
        self.buffer.clear();
        self.in_placeholder = false;
        i = self.delimiters.close.len() - 1; // Skip input[0] (the second byte)
    } else {
        // Lone closing byte — treat as literal part of key
        // Push it to buffer, then let scan_placeholder process input[0]
        self.buffer.push(self.delimiters.close[0]);
        i = 0; // Do NOT skip input[0] — let scan_placeholder handle it
    }
}
```

**In `flush()`** — emit deferred bytes before flushing buffer:
```rust
pub fn flush(mut self, out: &mut Vec<u8>) -> Result<()> {
    if self.pending_brace {
        out.push(self.delimiters.open[0]);
        self.pending_brace = false;
    }
    if self.pending_close_brace {
        self.buffer.push(self.delimiters.close[0]);
        self.pending_close_brace = false;
    }
    if self.in_placeholder {
        out.extend_from_slice(self.delimiters.open);
        self.in_placeholder = false;
    }
    out.extend_from_slice(&self.buffer);
    self.buffer.clear();
    Ok(())
}
```

### Fix 2: MiriBackend::open_append Cursor Position

**Problem:** `Cursor::new(existing)` initializes at position 0. Writes overwrite from the start instead of appending.

**Fix:** Set cursor position to end of existing data:

```rust
fn open_append(&self, path: &GuardedPath) -> Result<Box<dyn std::io::Write>> {
    let rel = normalize_rel(path);
    let state = self.state_for_guard_rc(path)?;
    let existing = state
        .lock()
        .expect("miri state poisoned")
        .read_file(&rel)
        .unwrap_or_default();
    let mut cursor = std::io::Cursor::new(existing);
    cursor.set_position(cursor.get_ref().len() as u64); // Seek to end
    Ok(Box::new(MiriWriteCursor {
        state,
        rel,
        cursor,
    }))
}
```

### Fix 3: Implement SlidingWindow and Remove stdout_log

**Problem:** `stdout_log: Arc<Mutex<Vec<u8>>>` accumulates every byte emitted to stdout. For large or infinite streams, this is unbounded O(N) memory. `ASSERT_STDOUT` must use an O(needle.len()) ring buffer instead.

**Architecture:**

All `ASSERT_STDOUT` needles are pre-registered into an observer list at execution start. `TeeWriter` pushes every chunk to all registered windows. Each `ASSERT_STDOUT` step checks its matching window.

**Files to modify:**
- `crates/oxdock-core/src/exec/io.rs` — Add `SlidingWindow`, update `TeeWriter`
- `crates/oxdock-core/src/exec/state.rs` — Replace `stdout_log` with `assert_windows`
- `crates/oxdock-core/src/exec/handlers.rs` — Update `assert_stdout`
- `crates/oxdock-core/src/exec/steps.rs` — Pre-register all assertion needles before execution starts
- `crates/oxdock-core/src/exec/mod.rs` — Update TeeWriter creation

**SlidingWindow struct:**
```rust
/// Maximum ring buffer capacity. Must be large enough to hold history
/// for any needle that might be assigned via update_needle after ENV mutations.
const MAX_NEEDLE_CAPACITY: usize = 1024;

pub(crate) struct SlidingWindow {
    needle: Vec<u8>,
    ring: VecDeque<u8>,
    pub matched: bool,
}

impl SlidingWindow {
    pub fn new(needle: Vec<u8>) -> Self {
        Self {
            ring: VecDeque::with_capacity(needle.len().min(MAX_NEEDLE_CAPACITY)),
            needle,
            matched: false,
        }
    }

    pub fn push_chunk(&mut self, chunk: &[u8]) {
        if self.matched { return; }
        for &byte in chunk {
            self.ring.push_back(byte);
            if self.ring.len() > MAX_NEEDLE_CAPACITY {
                self.ring.pop_front();
            }
            self.check_match();
        }
    }

    /// Replace needle without discarding ring history.
    /// Re-evaluates current ring against updated needle.
    pub fn update_needle(&mut self, new_needle: Vec<u8>) {
        if self.matched { return; }
        self.needle = new_needle;
        // Ring retains history up to MAX_NEEDLE_CAPACITY — check against new needle
        self.check_match();
    }

    fn check_match(&mut self) {
        if self.matched || self.ring.len() < self.needle.len() { return; }
        let start = self.ring.len() - self.needle.len();
        if self.ring.iter().skip(start).zip(self.needle.iter()).all(|(a, b)| a == b) {
            self.matched = true;
        }
    }
}
```

**TeeWriter update:**
```rust
struct TeeWriter {
    inner: Option<SharedOutput>,
    windows: Arc<Mutex<HashMap<usize, SlidingWindow>>>,
}

impl Write for TeeWriter {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        // Forward to downstream (streaming)
        match &self.inner {
            Some(inner) => { inner.lock()?.write_all(buf)?; }
            None => io::stdout().write_all(buf)?,
        }
        // Push to ALL registered assertion windows (O(1) per byte per window)
        if let Ok(mut windows) = self.windows.lock() {
            for window in windows.values_mut() {
                window.push_chunk(buf);
            }
        }
        Ok(buf.len())
    }
}
```

**Re-expansion on ENV/InheritEnv mutation (steps.rs):**
After any environment-mutating step, re-expand all unmatched window needles. Extract into a helper function.

```rust
fn reexpand_assert_windows<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    steps: &[Step],
) -> Result<()> {
    let ctx = cx.state.command_ctx()?;
    let mut windows = cx.state.assert_windows.lock()?;
    for (idx, step) in steps.iter().enumerate() {
        if let StepKind::AssertStdout(needle) = &step.kind {
            if let Some(w) = windows.get_mut(&idx) {
                let rendered = expand_template_string(needle, &ctx);
                w.update_needle(rendered.into_bytes());
            }
        }
    }
    Ok(())
}
```

Call after both `StepKind::Env` and `StepKind::InheritEnv`:

```rust
StepKind::Env { key, value } => {

    reexpand_assert_windows(&mut cx, steps)?;
}
StepKind::InheritEnv { keys } => {
    handlers::inherit_env(&mut cx, keys)?;
    reexpand_assert_windows(&mut cx, steps)?;
}
```

**ASSERT_STDOUT handler:**
Handles two modes: piped stdin (active consumption) and step-scope (check pre-registered window).

```rust
pub(super) fn assert_stdout<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    idx: usize,
    needle: &TemplateString,
) -> Result<()> {
    let ctx = cx.state.command_ctx()?;
    let rendered = super::expand_template(needle, &ctx);

    // Mode 1: Piped stdin — actively consume stream and check
    if let Some(input_stream) = cx.stdin.clone() {
        let mut guard = input_stream.lock()?;
        let mut window = SlidingWindow::new(rendered.into_bytes());
        let mut buf = [0u8; CHUNK_SIZE];
        loop {
            let n = guard.read(&mut buf)?;
            if n == 0 { break; }
            window.push_chunk(&buf[..n]);
            // Tee to downstream — preserve pipeline continuity
            if let Some(ref out) = cx.out {
                write_stdout(out.clone(), |w| {
                    w.write_all(&buf[..n])?;
                    Ok(())
                })?;
            }
        }
        if !window.matched {
            bail!("step {}: ASSERT_STDOUT did not contain '{}'", idx + 1, rendered);
        }
        return Ok(());
    }

    // Mode 2: Step scope — check pre-registered window
    let windows = cx.state.assert_windows.lock()
        .map_err(|_| anyhow!("assert_windows poisoned"))?;
    match windows.get(&idx) {
        Some(w) if w.matched => Ok(()),
        _ => bail!("step {}: ASSERT_STDOUT did not contain '{}'", idx + 1, rendered),
    }
}
```

**Key property:** O(needle.len()) memory per assertion. All windows are fed by every TeeWriter write. Multiple sequential assertions work because each has its own window registered at startup. No 1-step lookahead needed.

**API:**
```rust
const MAX_PLACEHOLDER_SCAN: usize = 1024;
const CHUNK_SIZE: usize = 8192; // Standard chunk size for all I/O handlers

/// Configurable delimiter syntax for template expansion.
pub struct TemplateDelimiters {
    pub open: &'static [u8],   // e.g., b"{{"
    pub close: &'static [u8],  // e.g., b"}}"
}

impl Default for TemplateDelimiters {
    fn default() -> Self {
        Self { open: b"{{", close: b"}}" }
    }
}

pub struct StreamingExpand {
    buffer: Vec<u8>,           // Key payload only (no open delimiter prefix)
    overrides: HashMap<String, String>,
    env: HashMap<String, String>,
    in_placeholder: bool,
    pending_brace: bool,        // Trailing opening byte deferred across chunks
    pending_close_brace: bool,  // Trailing closing byte deferred across chunks
    delimiters: TemplateDelimiters,
}

impl StreamingExpand {
    pub fn new(overrides: &[(String, String)], env: &HashMap<String, String>) -> Self;
    pub fn process_bytes(&mut self, input: &[u8], out: &mut Vec<u8>) -> Result<usize>;
    pub fn flush(mut self, out: &mut Vec<u8>) -> Result<()>;
    pub fn expand_string(self, input: &str) -> Result<String>;
}
```

**State machine:** Normal → PlaceholderScan → Normal. `buffer` holds only key payload. `flush()` emits deferred bytes, then open delimiter prefix (once), then buffer.

**Chunk boundary handling:**
- `pending_brace`: If chunk ends with single opening byte while in Normal, defer to next chunk
- `pending_close_brace`: If chunk ends with single closing byte while in PlaceholderScan, defer to next chunk. On next chunk, if first byte confirms close delimiter, extract key and emit. If not, push the deferred byte to buffer and advance `i = 1` to prevent duplicate processing.

**Delimiters:** All byte constants (`b'{'`, `b'}'`, `b"{{"`, `b"}}"`) replaced with `self.delimiters.open[N]` and `self.delimiters.close[N]` lookups. Single-byte checks use `self.delimiters.open[0]` / `self.delimiters.close[0]`.

**Buffer size:** All `8192` literals replaced with `const CHUNK_SIZE: usize = 8192`.

**Lookup:** Strips `env:` and `script_env:` prefixes. Keys WITHOUT prefix only check overrides (not env). Overrides checked with both raw and normalized keys.
