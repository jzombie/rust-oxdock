# Plan: Streaming Template Engine + REPLACE Command

## Goal

Replace the string-based template expansion (`expand_with_lookup`) with a streaming `StreamingExpand` state machine. No command in the DSL should ever buffer large content. Add a `REPLACE` command that uses this streaming infrastructure to expand file/stdin content with `{{ env:KEY }}` placeholders.

This is a full refactor — no deprecation, no legacy APIs. Alpha software, clean break.

## Scope

### Part 1: Streaming Template Engine

Replace the entire expansion subsystem:

| Current | Replacement |
|---|---|
| `expand_with_lookup(input: &str) -> String` | `StreamingExpand::process_bytes(input: &[u8]) -> Result<Vec<u8>>` |
| `expand_script_env(input: &str) -> String` | `StreamingExpand::new(overrides, script_envs)` |
| `expand_command_env(input: &str) -> String` | `StreamingExpand::new(overrides, ctx.envs())` |
| `expand_template(t, ctx) -> String` | `StreamingExpand::new(overrides, ctx.envs())` |

**New API in `crates/sys/oxdock-process/src/expand.rs`:**

```rust
pub struct StreamingExpand {
    buffer: Vec<u8>,
    lookup: HashMap<String, String>,
}

impl StreamingExpand {
    /// Create with env vars and optional explicit overrides.
    /// Overrides take precedence over env vars.
    pub fn new(
        overrides: &[(String, String)],
        env: &HashMap<String, String>,
    ) -> Self;

    /// Process a chunk of input bytes, returning expanded output.
    /// Handles partial `{{ env:KEY }}` across chunk boundaries.
    pub fn process_bytes(&mut self, input: &[u8]) -> Result<Vec<u8>>;

    /// Flush remaining buffer. Incomplete placeholders are treated as literals.
    pub fn flush(self) -> Result<Vec<u8>>;

    /// Process a complete string (convenience for short command arguments).
    pub fn expand_string(self, input: &str) -> Result<String>;
}
```

**State machine for `process_bytes`:**
- Scans for `{{` opening
- Looks for `}}` closing
- If found: extract key, lookup value, emit expanded content
- If not found: leave in buffer for next chunk
- `flush()`: emit remaining buffer as-is (incomplete placeholders are literals)

**Helper functions (private):**
- `find_closing_braces(data: &[u8]) -> Option<usize>` — find `}}` after `{{`
- `extract_key(placeholder: &[u8]) -> Result<String>` — extract and trim key

### Part 3: Add REPLACE Command

**Grammar (`crates/oxdock-parser/src/dsl.pest`):**

```pest
replace_command = ${ "REPLACE" ~ (sep ~ argument)? ~ (sep ~ key_value)* }
key_value = ${ argument ~ "=" ~ argument }
```

**AST (`crates/oxdock-parser/src/ast.rs`):**

```rust
Replace {
    path: Option<TemplateString>,
    overrides: Vec<(String, TemplateString)>,
},
```

**Handler (`crates/oxdock-core/src/exec/handlers.rs`):**

```rust
pub(super) fn replace<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    idx: usize,
    path_opt: &Option<TemplateString>,
    overrides: &[(String, TemplateString)],
) -> Result<()> {
    let ctx = cx.state.command_ctx()?;

    // Resolve override values
    let resolved_overrides: Vec<(String, String)> = overrides
        .iter()
        .map(|(k, v)| (k.clone(), expand_template_string(v, &ctx)))
        .collect();

    let mut expander = StreamingExpand::new(&resolved_overrides, &ctx.envs());

    if let Some(path) = path_opt {
        // Streaming file read
        let rendered = expand_template_string(path, &ctx);
        let target = cx.state.fs.resolve_read(&cx.state.cwd, &rendered)
            .with_context(|| format!("step {}: REPLACE {}", idx + 1, rendered))?;
        let mut reader = cx.state.fs.open_read(&target)
            .with_context(|| format!("failed to open {}", target.display()))?;
        let mut buf = [0u8; 8192];
        loop {
            let n = reader.read(&mut buf)
                .with_context(|| format!("failed to read {}", target.display()))?;
            if n == 0 { break; }
            let expanded = expander.process_bytes(&buf[..n])?;
            write_stdout(cx.out.clone(), |w| {
                w.write_all(&expanded).context("failed to write output")?;
                Ok(())
            })?;
        }
    } else {
        // Streaming stdin
        if let Some(input_stream) = cx.stdin.clone() {
            let mut guard = input_stream.lock()
                .map_err(|_| anyhow!("failed to lock stdin for REPLACE"))?;
            let mut buf = [0u8; 8192];
            loop {
                let n = guard.read(&mut buf)
                    .context("failed to read from stdin")?;
                if n == 0 { break; }
                let expanded = expander.process_bytes(&buf[..n])?;
                write_stdout(cx.out.clone(), |w| {
                    w.write_all(&expanded).context("failed to write output")?;
                    Ok(())
                })?;
            }
        }
    }

    // Flush remaining buffer
    let final_bytes = expander.flush()?;
    if !final_bytes.is_empty() {
        write_stdout(cx.out.clone(), |w| {
            w.write_all(&final_bytes).context("failed to write output")?;
            Ok(())
        })?;
    }

    Ok(())
}
```

## Example Workflow

```oxdock
ENV CRATE_NAME=oxdock-fs
ENV CRATE_DESC="Filesystem abstractions"

# Stream expanded template to a file
WITH_IO [stdout=pipe:tmpl] REPLACE template.md
WITH_IO [stdin=pipe:tmpl] WRITE crates/oxdock-fs/README.md

# Use explicit overrides instead of env
WITH_IO [stdout=pipe:tmpl] REPLACE template.md CRATE_NAME=oxdock-core TITLE="Core"
WITH_IO [stdin=pipe:tmpl] WRITE crates/oxdock-core/README.md

# Conditional sections
[env:DEBUG]
WITH_IO [stdout=pipe:tmpl] REPLACE debug-section.md
WITH_IO [stdin=pipe:tmpl] APPEND output.md

# Verify
ASSERT_FILE crates/oxdock-fs/README.md "# oxdock-fs\n\nFilesystem abstractions"
```
