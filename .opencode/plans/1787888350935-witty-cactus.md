# Plan: Replace Hand-Rolled Markdown Parser with pulldown-cmark

## Goal

Replace the custom string-scanner markdown parser in `crates/oxdock-parser/src/markdown.rs` with `pulldown-cmark`. Remove `stdin:` fence metadata from the public API. Keep all other control directives (`env:`, `expect_error:`, `roots:unified`). Update README examples to use native DSL pipelines instead of hidden metadata.

## Critical Constraints

1. **`ECHO` expands templates eagerly.** `ECHO "Hello, {{ env:NAME }}!"` outputs `Hello, !` — the literal `{{ env:NAME }}` tags are destroyed before reaching any pipe. The only way to pipe unexpanded template content is `RAW_WRITE` → file → `READ` (which passes raw bytes through without expansion).

2. **`READ` does NOT expand templates.** It reads raw bytes from file/stdin and writes them verbatim to stdout. This is the correct command for piping raw template content.

3. **Control directives are required.** `expect_error:`, `roots:unified`, and `env:` are execution control flags used by `docs_conformance.rs`. They must be retained. Only `stdin:` is removed.

### 2. Rewrite `markdown.rs` using pulldown-cmark

**File:** `crates/oxdock-parser/src/markdown.rs`

Replace the 351-line hand-rolled scanner with ~120 lines using `pulldown_cmark`.

**Retained API:**
```rust
pub struct BlockMetadata {
    pub env: Vec<(String, String)>,
    // REMOVED: stdin field
    pub unified_roots: bool,
    pub expect_error: Option<String>,
}

pub struct FencedBlock {
    pub line_no: usize,
    pub info_string: String,
    pub metadata: BlockMetadata,
    pub body: String,
}

pub fn extract_fenced_blocks(markdown: &str, lang: &str) -> Result<Vec<FencedBlock>>;
```

**Implementation:**
- Use `Parser::new_ext(markdown, options).into_offset_iter()` to get `(Event, Range<usize>)` pairs.
- Build a line number map from newline byte offsets: `line_starts` vec, then `partition_point` to translate byte offset → 1-based line number.
- Filter `Event::Start(Tag::CodeBlock(CodeBlockKind::Fenced(info)))` where `info.trim().split_whitespace().next() == Some(lang)`.
- Collect `Event::Text` bodies, CRLF-normalize via `LineEnding::normalize()`.
- Parse control directives from info string using the same space-separated token scanner (keep `parse_metadata` but remove the `stdin` case).
- On unclosed fence, return error (same as current behavior).

**Deleted:** `stdin` variant from `parse_metadata`. `fence_ticks`, `first_token`, `skip_token` functions (replaced by pulldown-cmark).

### 5. Update README examples

**File:** `README.md`

**EXPAND (File mode)** — keep as-is:
```oxdock
RAW_WRITE template.md "Hello, {{ env:NAME }}!"
EXPAND template.md NAME="Alice"
ASSERT_STDOUT "Hello, Alice!"
```

**EXPAND (Stdin mode)** — new, using `RAW_WRITE` + `READ`:
```oxdock
RAW_WRITE tmpl.txt "Hello, {{ env:NAME }}!"
WITH_IO [stdout=pipe:raw_tmpl] READ tmpl.txt
WITH_IO [stdin=pipe:raw_tmpl] EXPAND NAME="Bob"
ASSERT_STDOUT "Hello, Bob!"
```

**WRITE (Stdin mode)** — rewrite, remove `stdin:` metadata:
```oxdock
RAW_WRITE input.txt "captured body"
WITH_IO [stdout=pipe:data] READ input.txt
WITH_IO [stdin=pipe:data] WRITE captured.txt
ASSERT_FILE captured.txt "captured body"
```

Remove all `stdin:...` fence info-string metadata from every `oxdock` code block.
