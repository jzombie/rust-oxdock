# Plan: Multi-Binding WITH_IO — Line-Buffered MPSC Fan-In + Synchronous Fan-Out

## Overview

Extend `WITH_IO` to support multiple bindings per stream type. All stream routing stays within `WITH_IO [...]`.

```dockerfile
// Fan-out: synchronous broadcast to two pipes
WITH_IO [stdout=pipe:branch1, stdout=pipe:branch2] ECHO "Hello World"

// Fan-in: line-buffered multiplexed interleaving (default)
WITH_IO [stdin=pipe:app_log, stdin=pipe:db_log] WRITE combined_system.log

// Fan-in: sequential concatenation for finite data
WITH_IO [stdin=concat(pipe:header, pipe:body)] WRITE final_payload.tar

// Fan-in with origin tagging
WITH_IO [stdin=pipe:app_log, stdin=pipe:db_log] WRITE tagged.log
// Produces:
//   [app_log] 2026-08-28 22:35:10 - Worker node healthy
//   [db_log] 2026-08-28 22:35:11 - Database migration completed
```

## Architecture

| Direction | Behavior | Mechanism |
|-----------|----------|-----------|
| **Multi-stdout (fan-out)** | Synchronous broadcast with backpressure | `MultiWriter` — writes to all outputs per chunk |
| **Multi-stdin (fan-in)** | Line-buffered MPSC multiplexing | `MultiplexReader` — thread-per-pipe → `sync_channel` → consumer |
| **Multi-stdin concat** | Sequential left-to-right | `ConcatReader` — reads each pipe to EOF in order |

### Why interleaved is the default for multi-stdin

Sequential fan-in breaks for live streams. If `pipe:app_log` is a continuous RUN_BG daemon, it never emits EOF. The sequential reader blocks forever on `pipe:app_log.read()`, starving `pipe:db_log`. `db_log`'s pipe buffer fills (64 KB on Linux), then `db_log`'s writer blocks on `write()`, deadlocking the pipeline.

### OOM Safeguards

| Safeguard | Mechanism |
|-----------|-----------|
| **Hard buffer ceiling** | `MAX_LINE_LEN = 64 KiB` per worker thread |
| **Forced chunk flushing** | Buffer force-flushed at `MAX_LINE_LEN` without newline — split across atomic messages |
| **Bounded channel** | `sync_channel(N)` — worker blocks on `send()` when channel full, propagating backpressure upstream |
| **`is_partial` tagging** | Consumer can detect forced flushes for structural metadata |

### 4. IO: `crates/oxdock-core/src/exec/io.rs`

Add `StreamMessage`, `MultiplexReader`, `MultiWriter`, and `ConcatReader`:

```rust
use std::collections::VecDeque;
use std::io::{self, Read, Write};
use std::sync::{Arc, Mutex, mpsc};

/// Hard buffer ceiling per worker thread. Lines exceeding this are force-flushed
/// as partial messages to prevent OOM from unbounded buffering.
const MAX_LINE_LEN: usize = 64 * 1024; // 64 KiB

/// Bounded channel capacity. When the consumer is slow, workers block on send(),
/// propagating backpressure through the OS pipe buffer to the upstream producer.
const MPSC_CHANNEL_BOUND: usize = 64;

/// Message sent from a worker thread through the bounded MPSC channel.
pub(super) struct StreamMessage {
    pub origin: Arc<str>,
    pub payload: Vec<u8>,
    /// `true` if flushed due to `MAX_LINE_LEN` rather than a newline boundary.
    pub is_partial: bool,
}

/// Line-buffered multiplexed reader. Spawns a thread per input pipe.
/// Each thread scans bytes for newline boundaries (0x0A) and sends complete
/// lines through a bounded mpsc channel. The main thread reads from the channel.
pub(super) struct MultiplexReader {
    rx: mpsc::Receiver<StreamMessage>,
    pending: VecDeque<u8>,
}

impl MultiplexReader {
    pub(super) fn new(inputs: Vec<(Arc<str>, SharedInput)>) -> Self {
        let (tx, rx) = mpsc::sync_channel(MPSC_CHANNEL_BOUND);
        for (origin, input) in inputs {
            let tx = tx.clone();
            std::thread::spawn(move || {
                process_stream_pipe(input, origin, tx);
            });
        }
        // Drop original sender; thread clones hold the channel open.
        // When all threads exit, rx.recv() returns Err and signals EOF.
        drop(tx);
        Self {
            rx,
            pending: VecDeque::new(),
        }
    }
}

/// Worker thread loop: reads from a pipe, buffers until newline or MAX_LINE_LEN,
/// sends complete or forced-flush lines through the bounded channel.
fn process_stream_pipe(
    input: SharedInput,
    origin: Arc<str>,
    tx: mpsc::SyncSender<StreamMessage>,
) {
    let chunk_buf = &mut [0u8; CHUNK_SIZE];
    let mut line_buf = Vec::with_capacity(CHUNK_SIZE);

    loop {
        let n = {
            let mut guard = match input.lock() {
                Ok(g) => g,
                Err(_) => return,
            };
            match guard.read(chunk_buf) {
                Ok(n) => n,
                Err(_) => return,
            }
        };
        if n == 0 {
            break; // EOF
        }

        for &byte in &chunk_buf[..n] {
            line_buf.push(byte);

            if byte == b'\n' {
                // Flush condition 1: newline encountered
                let payload = std::mem::take(&mut line_buf);
                let _ = tx.send(StreamMessage {
                    origin: origin.clone(),
                    payload,
                    is_partial: false,
                });
            } else if line_buf.len() >= MAX_LINE_LEN {
                // Flush condition 2: hard buffer cap reached without newline
                let payload = std::mem::take(&mut line_buf);
                let _ = tx.send(StreamMessage {
                    origin: origin.clone(),
                    payload,
                    is_partial: true,
                });
            }
        }
    }

    // Flush any remaining bytes at EOF (partial line without trailing newline)
    if !line_buf.is_empty() {
        let _ = tx.send(StreamMessage {
            origin,
            payload: line_buf,
            is_partial: false,
        });
    }
}

impl Read for MultiplexReader {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        // Drain any leftover bytes from the previous message
        while !self.pending.is_empty() && !buf.is_empty() {
            let byte = self.pending.pop_front().unwrap();
            let mut written = 0;
            buf[written] = byte;
            written += 1;
            while written < buf.len() && !self.pending.is_empty() {
                buf[written] = self.pending.pop_front().unwrap();
                written += 1;
            }
            return Ok(written);
        }
        // Block on channel for next complete or forced-flush line
        match self.rx.recv() {
            Ok(msg) => {
                let take = msg.payload.len().min(buf.len());
                buf[..take].copy_from_slice(&msg.payload[..take]);
                if take < msg.payload.len() {
                    self.pending.extend(msg.payload.into_iter().skip(take));
                }
                Ok(take)
            }
            Err(_) => Ok(0), // All senders dropped = all pipes EOF'd
        }
    }
}

/// Synchronous broadcast writer. Writes to all outputs per chunk.
pub(super) struct MultiWriter {
    outputs: Vec<SharedOutput>,
}

impl MultiWriter {
    pub(super) fn new(outputs: Vec<SharedOutput>) -> Self {
        Self { outputs }
    }
}

impl Write for MultiWriter {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        for out in &self.outputs {
            let mut guard = out.lock().map_err(|_| io::Error::other("output poisoned"))?;
            guard.write_all(buf)?;
        }
        Ok(buf.len())
    }

    fn flush(&mut self) -> io::Result<()> {
        for out in &self.outputs {
            let mut guard = out.lock().map_err(|_| io::Error::other("output poisoned"))?;
            guard.flush()?;
        }
        Ok(())
    }
}

/// Sequential left-to-right reader. Reads each pipe to EOF in declaration order.
pub(super) struct ConcatReader {
    inputs: Vec<SharedInput>,
    current: usize,
}

impl ConcatReader {
    pub(super) fn new(inputs: Vec<SharedInput>) -> Self {
        Self { inputs, current: 0 }
    }
}

impl Read for ConcatReader {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        while self.current < self.inputs.len() {
            let n = {
                let mut guard = self.inputs[self.current]
                    .lock()
                    .map_err(|_| io::Error::other("concat input poisoned"))?;
                guard.read(buf)?
            };
            if n > 0 {
                return Ok(n);
            }
            self.current += 1;
        }
        Ok(0)
    }
}
```

pub(super) fn with_io<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    idx: usize,
    bindings: &[IoBinding],
    cmd: &StepKind,
) -> Result<()> {
    let inner_step = Step {
        guard: None,
        kind: cmd.clone(),
        scope_enter: 0,
        scope_exit: 0,
    };
    let steps = vec![inner_step];

    let mut stdin_bindings: Vec<&IoBinding> = Vec::new();
    let mut stdout_bindings: Vec<&IoBinding> = Vec::new();
    let mut stderr_bindings: Vec<&IoBinding> = Vec::new();

    for binding in bindings {
        if let Some(pipe) = &binding.pipe {
            cx.state.io.ensure_script_pipe(pipe);
        }
        match binding.stream {
            IoStream::Stdin => stdin_bindings.push(binding),
            IoStream::Stdout => stdout_bindings.push(binding),
            IoStream::Stderr => stderr_bindings.push(binding),
        }
    }

    let (step_stdin, next_expose_stdin) = resolve_stdin(cx, idx, &stdin_bindings)?;
    let step_stdout = resolve_stdout(cx, idx, &stdout_bindings)?;
    let step_stderr = resolve_stderr(cx, idx, &stderr_bindings)?;

    super::steps::execute_steps(
        cx.state, cx.process, &steps,
        step_stdin, next_expose_stdin,
        step_stdout, step_stderr,
        false,
    )?;
    Ok(())
}

**`resolve_stdin()`** — dispatches between single, multiplexed, and concat:

```rust
fn resolve_stdin<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    idx: usize,
    bindings: &[&IoBinding],
) -> Result<(Option<SharedInput>, bool)> {
    if bindings.is_empty() {
        return Ok((None, false));
    }

    let has_concat = bindings.iter().any(|b| b.concat);

    if has_concat {
        // Sequential concatenation
        let mut inputs = Vec::new();
        for binding in bindings {
            if let Some(pipe) = &binding.pipe {
                let reader = cx.state.io.input_pipe(pipe).ok_or_else(|| {
                    anyhow!("step {}: stdin pipe '{}' is undefined", idx + 1, pipe)
                })?;
                inputs.push(reader);
            } else if let Some(stdin) = &cx.stdin {
                inputs.push(stdin.clone());
            }
        }
        Ok((Some(Arc::new(Mutex::new(ConcatReader::new(inputs)))), true))
    } else if bindings.len() == 1 {
        // Single binding: current behavior (no change)
        let binding = bindings[0];
        let reader = if let Some(pipe) = &binding.pipe {
            Some(cx.state.io.input_pipe(pipe).ok_or_else(|| {
                anyhow!("step {}: stdin pipe '{}' is undefined", idx + 1, pipe)
            })?)
        } else {
            cx.stdin.clone()
        };
        Ok((reader, true))
    } else {
        // Multiple bindings: line-buffered MPSC multiplexing
        let mut inputs = Vec::new();
        for binding in bindings {
            let origin: Arc<str> = binding
                .pipe
                .clone()
                .unwrap_or_default()
                .into();
            if let Some(pipe) = &binding.pipe {
                let reader = cx.state.io.input_pipe(pipe).ok_or_else(|| {
                    anyhow!("step {}: stdin pipe '{}' is undefined", idx + 1, pipe)
                })?;
                inputs.push((origin, reader));
            } else if let Some(stdin) = &cx.stdin {
                inputs.push((origin, stdin.clone()));
            }
        }
        Ok((
            Some(Arc::new(Mutex::new(MultiplexReader::new(inputs)))),
            true,
        ))
    }
}
```

**`resolve_stdout()`** — dispatches between single and multi:

```rust
fn resolve_stdout<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    idx: usize,
    bindings: &[&IoBinding],
) -> Result<Option<StreamHandle>> {
    if bindings.is_empty() {
        return Ok(cx.out.clone());
    }
    if bindings.len() == 1 {
        return resolve_single_stdout(cx, idx, bindings[0]);
    }
    // Multiple bindings: MultiWriter broadcast
    let mut outputs = Vec::new();
    for binding in bindings {
        if let Some(pipe) = &binding.pipe {
            let ep = cx.state.io.output_pipe_stdout(pipe).ok_or_else(|| {
                anyhow!("step {}: stdout pipe '{}' is undefined", idx + 1, pipe)
            })?;
            outputs.push(ep.to_stream_handle().into_shared_output());
        } else if let Some(StreamHandle::Stream(out)) = &cx.out {
            outputs.push(out.clone());
        }
    }
    let writer = Arc::new(Mutex::new(MultiWriter::new(outputs)));
    Ok(Some(StreamHandle::Stream(writer)))
}
```

## Key Design Decisions

- **Line-buffered atomicity**: Workers scan byte-by-byte for `0x0A` (newline) and send complete lines as single `StreamMessage` payloads. No byte-level interleaving corruption.
- **`MAX_LINE_LEN = 64 KiB`**: Hard ceiling per worker thread. Lines exceeding this are force-flushed as `is_partial: true` messages, preventing OOM from unbounded buffering.
- **`sync_channel(64)` bounded capacity**: When the consumer is slow, workers block on `send()`, the OS pipe buffer fills, and native process-level backpressure propagates to the upstream producer (RUN child or pipe writer).
- **`is_partial` tagging**: Consumer can detect forced flushes (`is_partial == true`) for structural metadata — e.g., `[LINE EXCEEDED 64KiB TRUNCATED]` indicator or suppressed line-prefix headers on continuation chunks.
- **EOF partial line cleanup**: If a stream terminates without trailing `\n`, the worker flushes the remaining buffer as a final `is_partial: false` message to prevent line splicing with active streams.
- **Fan-out is synchronous**: No threading. `MultiWriter` writes to all outputs per chunk with backpressure. If one output is slow, all slow down together — correct for a synchronous DSL step.
- **`concat()` is explicit for batch**: Avoids thread overhead and guarantees order for finite/build data.
- **Last-writer-wins for defaults**: If a block sets `stdout=pipe:log` and a command inside sets `stdout=pipe:a, stdout=pipe:b`, the command's bindings replace the block's. Matches current `merge_bindings()` semantics.
- **Bare bindings in multi-context**: `[stdout=pipe:log, stdout]` fans out to pipe:log AND inherits parent stdout. `[stdin=pipe:data, stdin]` reads pipe:data first, then parent stdin.
- **No new AST variants**: All routing stays in `IoBinding` / `WITH_IO`.
- **Thread safety**: `SharedInput`/`SharedOutput` are `Arc<Mutex<dyn Read/Write + Send>>` — `Clone + Send + Sync`. `std::thread::spawn` is already used in `oxdock-process/src/shell_manager.rs`.
