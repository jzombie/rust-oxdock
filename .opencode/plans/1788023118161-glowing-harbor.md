# Replace `assemble_readme` with OxDock DSL

## Goal

Replace the imperative Rust `assemble_readme` function in `crates/docs-gen/src/sections.rs` with an OxDock DSL script that uses `GLOB`, `FOR`, `LET`, `READ`, and `APPEND`.

## Current Behavior

The Rust function:
1. Reads all `*.md` files from `docs/sections/`
2. Sorts them alphabetically (produces numeric order: `00` through `15`)
3. Concatenates with blank-line separation and line-ending normalization
4. Writes to `README.md` (or custom `output` path)

## DSL Limitations

- No string manipulation (no `TRIM`, `REPLACE`, `SUBSTR`)
- No conditional logic (no `IF`)
- `READ` writes to stdout, not to a variable — must use `WITH_IO [stdout=pipe:name]` piping
- Line ending normalization not possible in DSL

## Approach

Replace the body of `assemble_readme` with a DSL script that:
1. Uses `LET $sections = GLOB("docs/sections/*.md")` to collect files
2. Iterates with `FOR`, piping `READ` output through `APPEND` via named pipes
3. Uses `RAW_WRITE` to truncate the target before the loop (prevents accumulation)
4. Uses `APPEND "README.md" "\n\n"` as separator before each section
5. The Rust function becomes a thin wrapper that builds the script string and calls `parse_script` + `run_steps_with_context_result_with_io`

## DSL Script Pattern (Pattern A: Sandboxed Isolation)

Use `temp` as `local_fs_root` and `repo_root` as `build_context_root`. Switch workspace scopes inside the loop to read from repo and write to temp:

```oxdock
WORKSPACE LOCAL
RAW_WRITE "README.md" ""

WORKSPACE BUILD_CONTEXT
LET $sections = GLOB("docs/sections/*.md")

FOR $f IN $sections {
    WORKSPACE BUILD_CONTEXT
    WITH_IO [stdout=pipe:sec] READ "$f"

    WORKSPACE LOCAL
    APPEND "README.md" "\n\n"
    WITH_IO [stdin=pipe:sec] APPEND "README.md"
}
```

- `WORKSPACE LOCAL` before `RAW_WRITE` — truncate in temp
- `WORKSPACE BUILD_CONTEXT` before `GLOB` — resolve files against repo
- Inside loop: `WORKSPACE BUILD_CONTEXT` before `READ` (source files in repo), `WORKSPACE LOCAL` before `APPEND` (output in temp)
- `APPEND` without contents reads from stdin — `WITH_IO [stdin=pipe:sec]` feeds the piped `READ` output

## Files to Modify

### 1. `crates/docs-gen/src/sections.rs`

Replace the Rust function body with DSL script execution:

```rust
use anyhow::Result;
use oxdock_core::{ExecIo, run_steps_with_context_result_with_io};
use oxdock_fs::GuardedPath;
use oxdock_parser::parse_script;
use std::path::Path;

pub fn assemble_readme(repo_root: &Path, output: Option<&Path>) -> Result<()> {
    let out_path = output
        .map(|p| p.to_path_buf())
        .unwrap_or_else(|| repo_root.join("README.md"));

    // Pattern A: temp = local_fs (sandboxed writes), repo = build_context (file reads)
    // Workspace scopes switch inside the loop: BUILD_CONTEXT for READ, LOCAL for APPEND
    let script = r#"
WORKSPACE LOCAL
RAW_WRITE "README.md" ""

WORKSPACE BUILD_CONTEXT
LET $sections = GLOB("docs/sections/*.md")

FOR $f IN $sections {
    WORKSPACE BUILD_CONTEXT
    WITH_IO [stdout=pipe:sec] READ "$f"

    WORKSPACE LOCAL
    APPEND "README.md" "\n\n"
    WITH_IO [stdin=pipe:sec] APPEND "README.md"
}"#;

    let root = GuardedPath::new_root(repo_root)?;
    let temp = GuardedPath::tempdir()?;
    let steps = parse_script(script)?;
    run_steps_with_context_result_with_io(temp.as_guarded_path(), &root, &steps, ExecIo::new())?;

    // Unconditionally copy assembled README from sandbox to final destination
    if let Some(parent) = out_path.parent() {
        std::fs::create_dir_all(parent)?;
    }
    std::fs::copy(temp.join("README.md")?, &out_path)?;

    Ok(())
}
```
