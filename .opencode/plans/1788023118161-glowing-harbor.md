# Decouple Expression Evaluation from Command Execution

## Goal

Centralize all `$variable` interpolation and expression evaluation in the step dispatch loop (`steps.rs`). Command handlers receive only fully-evaluated, concrete `&str` values — they are agnostic to whether a value came from a `$variable`, `FOR` loop, `GLOB()`, or raw literal.

## Architecture

```
Phase 1: Parse       → StepKind AST with Arg fields
Phase 2: Pre-Dispatch → resolve Arg → concrete String (in steps.rs)
Phase 3: Expand      → {{ env:KEY }} expansion (in steps.rs)
Phase 4: Execute     → handlers receive &str, do I/O only
```

## Step 1: Add `Arg` type to parser AST

**File:** `crates/oxdock-parser/src/ast.rs`

Add a new enum that replaces raw `TemplateString` in `StepKind` fields:

```rust
#[derive(Debug, Clone, Eq, PartialEq)]
pub enum Arg {
    /// Raw string — no variable resolution or template expansion.
    /// Used by RAW_WRITE contents.
    Literal(String),
    /// Template string — undergoes $variable resolution then {{ env:KEY }} expansion.
    Template(TemplateString),
}

impl Arg {
    pub fn as_str(&self) -> &str {
        match self {
            Arg::Literal(s) => s,
            Arg::Template(t) => &t.0,
        }
    }
}

// Conversions
impl From<String> for Arg { fn from(s: String) -> Self { Arg::Template(TemplateString(s)) } }
impl From<&str> for Arg { fn from(s: &str) -> Self { Arg::Template(TemplateString(s.to_string())) } }
impl From<TemplateString> for Arg { fn from(t: TemplateString) -> Self { Arg::Template(t) } }
```

**Display impl:** Each variant displays its raw content (not evaluated result) for round-trip stability:
```rust
impl fmt::Display for Arg {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Arg::Literal(s) => write!(f, "{}", s),
            Arg::Template(t) => write!(f, "{}", t),
        }
    }
}
```

```rust
/// Evaluate an Arg to a concrete String using ExecState directly.
/// Used by pre_register_assertions where StepCtx is not available.
pub(super) fn resolve_arg_state<P: ProcessManager>(
    arg: &Arg,
    state: &ExecState<P>,
) -> Result<String> {
    match arg {
        Arg::Literal(s) => Ok(s.clone()),
        Arg::Template(t) => {
            let dollar_resolved = resolve_dollar_vars(&t.0, state);
            let ctx = state.command_ctx()?;
            let expander = oxdock_process::StreamingExpand::new(&[], ctx.envs());
            expander
                .expand_string(&dollar_resolved)
                .ok_or_else(|| anyhow!("failed to expand template: {}", t.0))
        }
    }
}

/// Evaluate an Arg to a concrete String using StepCtx.
/// Delegates to resolve_arg_state for the actual work.
pub(super) fn resolve_arg<P: ProcessManager>(
    arg: &Arg,
    cx: &StepCtx<'_, P>,
) -> Result<String> {
    resolve_arg_state(arg, cx.state)
}

/// Evaluate an optional Arg.
pub(super) fn resolve_arg_opt<P: ProcessManager>(
    arg: &Option<Arg>,
    cx: &StepCtx<'_, P>,
) -> Result<Option<String>> {
    match arg {
        Some(a) => Ok(Some(resolve_arg(a, cx)?)),
        None => Ok(None),
    }
}

/// Evaluate a list of (key, Arg) overrides.
pub(super) fn resolve_overrides<P: ProcessManager>(
    overrides: &[(String, Arg)],
    cx: &StepCtx<'_, P>,
) -> Result<Vec<(String, String)>> {
    overrides.iter().map(|(k, v)| Ok((k.clone(), resolve_arg(v, cx)?))).collect()
}
```

Also keep `evaluate_expr`, `evaluate_glob`, `resolve_dollar_vars` here (moved from handlers.rs).

## Step 6: Rewrite dispatch loop to pre-evaluate arguments

**File:** `crates/oxdock-core/src/exec/steps.rs`

### AssertStdout needle strategy

`SlidingWindow` needles must be registered BEFORE the process starts producing stdout. Three concerns:

1. **Variable needles** — can't be resolved at pre-registration time; must be resolved at iteration start
2. **Stale needles in loops** — needles must be re-resolved each iteration when variables change
3. **Key collisions** — nested `execute_steps` calls use overlapping step indexes

Solution: **Generation-scoped keys** + **resolve once per iteration boundary**.

```rust
/// Pre-register AssertStdout steps. Needles without $variable are resolved
/// eagerly. Needles with $variable are registered with a placeholder and
/// resolved at iteration start.
fn pre_register_assertions<P: ProcessManager>(
    state: &mut ExecState<P>,
    steps: &[Step],
    generation: usize,
) -> Result<()> {
    let mut windows = match state.assert_windows.lock() {
        Ok(guard) => guard,
        Err(_) => bail!("assert_windows poisoned"),
    };
    for (idx, step) in steps.iter().enumerate() {
        if let StepKind::AssertStdout(needle) = &step.kind {
            let key = (generation, idx);
            if needle.as_str().contains('$') {
                // Variable needle — only insert placeholder if not already resolved
                // by sync_iteration_assert_needles (for_loop iteration start).
                windows.entry(key).or_insert_with(|| SlidingWindow::new(Vec::new()));
            } else {
                // Static needle — resolve eagerly via ExecState (no StepCtx needed)
                let rendered = args::resolve_arg_state(needle, state)?;
                windows.insert(key, SlidingWindow::new(rendered.into_bytes()));
            }
        }
    }
    Ok(())
}

/// Resolve variable-containing AssertStdout needles for a set of body steps.
/// Called ONCE at the start of each for_loop iteration, NOT before every step.
/// Creates fresh SlidingWindow instances that will accumulate output across
/// all steps in the iteration.
pub(super) fn sync_iteration_assert_needles<P: ProcessManager>(
    cx: &StepCtx<'_, P>,
    steps: &[Step],
    generation: usize,
) -> Result<()> {
    let mut windows = match cx.state.assert_windows.lock() {
        Ok(guard) => guard,
        Err(_) => bail!("assert_windows poisoned"),
    };
    for (idx, step) in steps.iter().enumerate() {
        if let StepKind::AssertStdout(needle) = &step.kind
            && needle.as_str().contains('$')
        {
            let key = (generation, idx);
            let rendered = args::resolve_arg(needle, cx)?;
            // Fresh window — clears stale buffer/state from prior iteration
            windows.insert(key, SlidingWindow::new(rendered.into_bytes()));
        }
    }
    Ok(())
}

/// Get the current assert generation counter value.
/// Used by for_loop to pass to sync_iteration_assert_needles.
pub(super) fn current_assert_generation() -> usize {
    ASSERT_GENERATION.load(Ordering::Relaxed)
}
```

### Dispatch loop

Each `execute_steps` invocation gets a unique `generation` counter. The counter is monotonically increasing across the entire script execution, preventing key collisions between nested scopes.

```rust
// Global generation counter for assert_windows key scoping
static ASSERT_GENERATION: AtomicUsize = AtomicUsize::new(0);

pub(super) fn execute_steps<P: ProcessManager>(
    state: &mut ExecState<P>,
    process: &mut P,
    steps: &[Step],
    stdin: Option<SharedInput>,
    expose_stdin: bool,
    out: Option<StreamHandle>,
    err: Option<StreamHandle>,
    wait_at_end: bool,
) -> Result<()> {
    let generation = ASSERT_GENERATION.fetch_add(1, Ordering::Relaxed);

    // Pre-register AssertStdout windows for this scope
    pre_register_assertions(state, steps, generation)?;

    for (idx, step) in steps.iter().enumerate() {
        // ... scope_enter, guard_check ...

        let step_result: Result<()> = if !should_run {
            Ok(())
        } else {
            let mut cx = StepCtx { state, process, /* ... */ };
            match &step.kind {
                // ... other handlers ...
                StepKind::Run(cmd) => {
                    let cmd = args::resolve_arg(cmd, &cx)?;
                    handlers::run(&mut cx, idx, &cmd)
                }
                StepKind::Echo(msg) => {
                    let msg = args::resolve_arg(msg, &cx)?;
                    handlers::echo(&mut cx, &msg)
                }
                StepKind::RunBg(cmd) => {
                    let cmd = args::resolve_arg(cmd, &cx)?;
                    handlers::run_bg(&mut cx, idx, &cmd)
                }
                StepKind::AssertStdout(msg) => {
                    let msg = args::resolve_arg(msg, &cx)?;
                    handlers::assert_stdout(&mut cx, generation, idx, &msg)
                }
                // ... remaining handlers ...
            }
        };
        // ... scope_exit, check_bg ...
    }
    // ... wait_at_end ...

    // Cleanup: remove all assert_windows entries for this generation
    // to prevent memory accumulation across iterations and nested scopes.
    if let Ok(mut windows) = state.assert_windows.lock() {
        windows.retain(|(gen, _), _| *gen != generation);
    }

    Ok(())
}
```

### `assert_stdout` handler

Receives `generation` and `idx` to look up the correct `SlidingWindow`:

```rust
pub(super) fn assert_stdout<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    generation: usize,
    idx: usize,
    needle: &str,
) -> Result<()> {
    let key = (generation, idx);
    let matched = {
        let mut windows = match cx.state.assert_windows.lock() {
            Ok(guard) => guard,
            Err(_) => bail!("assert_windows poisoned"),
        };
        if let Some(w) = windows.get_mut(&key) {
            let matched = w.is_matched();
            matched
        } else {
            bail!("step {}: ASSERT_STDOUT window not found", idx + 1)
        }
    };
    if !matched {
        bail!(
            "step {}: ASSERT_STDOUT failed: stdout did not contain \"{}\"",
            idx + 1,
            needle
        );
    }
    Ok(())
}
```

### `reexpand_assert_windows` for ENV / INHERIT_ENV

Re-resolves ALL needles (static and variable) after environment mutations. Uses `update_needle` to preserve accumulated stream buffers and match state:

```rust
fn reexpand_assert_windows<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    steps: &[Step],
    generation: usize,
) -> Result<()> {
    let mut windows = match cx.state.assert_windows.lock() {
        Ok(guard) => guard,
        Err(_) => bail!("assert_windows poisoned"),
    };
    for (idx, step) in steps.iter().enumerate() {
        if let StepKind::AssertStdout(needle) = &step.kind
            && let key = (generation, idx)
            && let Some(w) = windows.get_mut(&key)
        {
            let rendered = args::resolve_arg(needle, cx)?;
            // update_needle preserves ring buffer history and matched state
            w.update_needle(rendered.into_bytes());
        }
    }
    Ok(())
}
```

## Step 8: Add scope snapshot helpers on `ExecState`

**File:** `crates/oxdock-core/src/exec/state.rs`

No RAII guard — use explicit push/pop to avoid holding `&mut ExecState` across execution calls:

```rust
impl<P: ProcessManager> ExecState<P> {
    /// Push a combined scope frame: variable scope + cwd/root/envs snapshot.
    /// Returns the snapshot for later restoration.
    pub(super) fn push_scope_frame(&mut self) -> ScopeSnapshot {
        self.push_var_scope();
        ScopeSnapshot {
            cwd: self.cwd.clone(),
            root: self.fs.root().clone(),
            envs: Arc::clone(&self.envs),
        }
    }

    /// Pop the variable scope and restore cwd/root/envs from the snapshot.
    pub(super) fn pop_scope_frame(&mut self, snapshot: ScopeSnapshot) {
        self.pop_var_scope();
        self.cwd = snapshot.cwd;
        self.fs.set_root(&snapshot.root);
        self.envs = snapshot.envs;
    }
}
```

**File:** `crates/oxdock-core/src/exec/handlers.rs`

Update `for_loop` to use push/pop and resolve assertion needles once per iteration:

```rust
pub(super) fn for_loop<P: ProcessManager>(
    cx: &mut StepCtx<'_, P>,
    var: &str,
    in_expr: &Expr,
    body: &[Step],
) -> Result<()> {
    let iterable = super::args::evaluate_expr(in_expr, cx)?;
    let clean_var = var.trim_start_matches('$').to_string();

    if let Value::List(items) = iterable {
        for item in items {
            let snap = cx.state.push_scope_frame();
            cx.state.set_var(clean_var.clone(), Value::String(item));

            // Resolve variable-dependent assertion needles ONCE per iteration.
            // This creates fresh SlidingWindow instances that accumulate output
            // across ALL steps in the iteration body.
            let generation = super::steps::current_assert_generation();
            super::steps::sync_iteration_assert_needles(cx, body, generation)?;

            let res = super::steps::execute_steps(
                cx.state, cx.process, body,
                cx.stdin.clone(), false,
                cx.out.clone(), cx.err.clone(), false,
            );
            cx.state.pop_scope_frame(snap);
            res?;
        }
        Ok(())
    } else {
        bail!("FOR loop requires a list iterable")
    }
}
```
