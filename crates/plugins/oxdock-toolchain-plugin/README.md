# oxdock-toolchain-plugin

Portable OxDock builder: provision pinned Rust toolchains and compile OxDock binaries on demand, all under a dedicated cache group with zero host dependencies.

> Part of the [OxDock](https://github.com/jzombie/rust-oxdock) workspace.

## Overview

The TOOLCHAIN module provisions a pinned Rust toolchain for a target
triple and compiles staged source into portable OxDock binaries, all
under a dedicated `toolchain` cache group. `TOOLCHAIN_ENSURE` lays out
the cache and returns the cached `cargo`, `rustc`, and sysroot paths.
`TOOLCHAIN_FETCH_SOURCE` snapshots local source into the cache (v1
bundle; pinned remote fetch is follow-up). `TOOLCHAIN_BUILD`
compiles with the cached toolchain only, provisioning automatically
when the binaries are missing and rebuilding only when the
fingerprint (source plus features plus profile plus toolchain
versions) goes stale. Linking rides a cached zig linker provisioned
beside the toolchain (Apple targets on macOS hosts use the host
compiler for its SDK explicitly), the cached `rustc` rides `RUSTC`,
and registries live in a cache-scoped `CARGO_HOME`, so no host
compiler, toolchain, or registry leaks in. Release is the default profile; `dev` is an
explicit opt-in whose outputs never read releasable. Import it with
`IMPORT [STD, TOOLCHAIN]` in a runner built with the `toolchain`
feature. The function reference below lists every entry with
signatures.

## Functions

### TOOLCHAIN_BUILD

**Signature:** `TOOLCHAIN_BUILD($triple, $manifest_dir, $features, $options) -> MAP`

**Contexts:** AST only

Build staged source with the cached toolchain.

Build staged source with the cached toolchain only. `triple` blanks
to host; `manifest_dir` must live inside the toolchain cache;
`features` is a LIST of STRING feature names; `options` is a MAP
with optional `profile` (`release` default, explicit `dev` opt-in).
Missing toolchain binaries provision automatically. Linking rides
the cached zig linker through `CARGO_ENCODED_RUSTFLAGS` (Apple
targets on macOS hosts use the host compiler for its SDK
explicitly). The cached `rustc` rides `RUSTC` and registries live
in a cache-scoped `CARGO_HOME`. Rebuilds only when the fingerprint
(source plus features plus profile plus linker plus toolchain
versions) is stale. Returns a MAP with `binary`, `profile`,
`releasable` (BOOL), and `metadata` (MAP).

### TOOLCHAIN_ENSURE

**Signature:** `TOOLCHAIN_ENSURE($triple) -> MAP`

**Contexts:** AST only

Ensure the cached toolchain for a target triple.

Ensure the pinned Rust toolchain for `triple` (blank means host) is
provisioned under the toolchain cache group. Returns a MAP with
`cargo`, `rustc`, `sysroot` (all guarded cache paths), and `triple`.
Idempotent: present binaries short-circuit before any network use.

### TOOLCHAIN_FETCH_SOURCE

**Signature:** `TOOLCHAIN_FETCH_SOURCE($hint) -> MAP`

**Contexts:** AST only

Snapshot local source into the toolchain cache.

Snapshot local source into the toolchain cache (v1 bundle). `hint`
anchors like READ: a leading `/` means the workspace root. Returns a
MAP with `manifest_dir` pointing inside the cache, never into the
local tree. Content addressed, so repeat calls are free.
